## 已处理问题

### 内容与信息架构

- 统一站点品牌为“策划宝产品知识库”。
- `_templates` 和仅供本地整理的 `99-收件箱` 不再公开。
- 公开文档不再链接到隐藏目录，避免死链和本地路径信息暴露。
- 表格内 Wiki 链接只在已确认的 Markdown 表格中转义，普通段落和代码块不受影响。
- 审计脚本将未转义的表格 Wiki 别名升级为阻断发布的错误。

### 渲染与交互

- 采用 Quartz 上游修复，消除虚拟文件夹页重复列表，不用 CSS 掩盖。
- 保留既有 `/knowledge` base path 修复，新增输出契约防止回归。
- 目录使用兼容布局，避免重复目录标识。
- 保留关系图、Mermaid、Callout 和内部 Wiki 链接能力。

### 安全与发布

- 构建前移除源 Markdown 原始 HTML，构建后再清洗最终 HTML AST，覆盖插件生成内容和嵌入别名注入路径。
- 增加 CSP、`nosniff`、Referrer Policy、Permissions Policy；禁用行内事件处理器。
- 知识服务端口只绑定服务器回环地址，公网统一经 Caddy 的 `/knowledge` 入口访问。
- HTML 与健康检查禁止缓存；CSS、JS、图标和分享图使用内容指纹及一年 immutable 缓存。
- 正式构建后执行输出契约：隐藏路径、品牌、base path、重复列表、资源哈希、元数据任一异常都会使容器启动失败。
- 部署脚本从公开知识库 URL 推导 Quartz base URL，避免再次生成错误根路径。

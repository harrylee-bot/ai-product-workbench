# AI 可视化原型工作台 V2 P0 完成计划

> 本文件是当前本机 Git 工作区的执行合同。代码来源只允许本机工作区和 GitHub 提交；外部磁盘副本不属于来源、依赖或验收环境。

## 目标

将可视化原型从“生成后静态投影”升级为可审阅、可交互、可构建、可分享、可导出的 V2 闭环。用户能够在项目内创建计划、审批生成、查看真实 iframe 预览、切换页面、操作控件、提交批注、确认或驳回版本、分享和撤销分享，并下载 HTML 与 React 产物。

## P0 验收条件

### 合同、权限与数据一致性

- [x] V2 合同定义计划、生成工作流、修订版本、页面、反馈、分享、导出、失败和取消状态。
- [x] API 路由、OpenAPI、生成类型和运行时解析使用同一合同；未知字段被拒绝。
- [x] 每个项目资源都执行项目成员权限和租户边界检查。
- [x] 所有写操作支持 `Idempotency-Key`；同一键和同一请求哈希重放原响应，不同请求哈希返回冲突。
- [x] 修订、反馈、分享和导出状态变更使用 `If-Match`/CAS，旧版本不能覆盖新版本。
- [x] 数据库迁移、唯一索引、回滚保护和迁移合同测试齐全。

### 真实工作台交互

- [x] `/projects/:id` 使用 V2 工作台入口，提供 Composer/计划、生成状态、页面列表、历史、反馈、分享和导出。
- [x] 现有项目、文件、知识、运行和发布能力仍有明确入口并保持可用，V2 入口由项目菜单和顶部入口直接打开。
- [x] 预览使用隔离 iframe；多页面导航、元素选择、点击、输入、选择框、提交和状态切换均是真实交互。
- [x] URL 可恢复当前 revision/page；刷新或直接打开链接不会丢失选择和页面上下文。
- [x] 取消、重试、确认、驳回、反馈解决、分享撤销和导出重试均有明确状态反馈。

### Temporal、DeerFlow 与构建

- [x] 生成、构建、预览冻结、分享和导出由版本化 Temporal workflow/activity 编排。
- [x] Temporal worker readiness 只有连接和 worker 创建成功后才返回 200；Compose、预检和部署等待使用同一健康端口。
- [x] DeerFlow 生成使用受控请求和固定输入；流式事件持续 heartbeat，取消信号能到达运行时并落库为 `cancelled`。
- [x] Build Worker 需要真实 Chromium；缺失浏览器时 fail-closed，不伪造成功。
- [x] Build Worker 在启动浏览器、加载页面和 DOM 检查阶段 heartbeat，并记录可诊断失败码。

### 对象存储、预览、分享与导出

- [x] 冻结 HTML/React 产物写入不可变对象；并发写入使用条件创建，已存在对象必须校验大小、媒体类型和 SHA-256。
- [x] 预览 token 绑定项目、revision、artifact checksum 和授权期限；预览 iframe 禁止 same-origin 和外部网络。
- [x] 分享只暴露公开投影，不泄露源码、凭据、内部 storage key 或未授权页面；撤销后立即失效。
- [x] HTML 与 React 导出都能真实下载，返回成功状态、字节数和 SHA-256；失败可查询并可幂等重试。
- [x] 导出失败、取消、重试和并发状态转换不会留下 queued/building 假成功或覆盖已取消结果。

### 清理与回归

- [x] 删除旧 V1 fallback、旧 pg-boss 原型工作流和不可达 API；保留迁移、协议、测试和知识源资产。
- [x] 合同/API/迁移/权限/幂等/CAS 单测和 PostgreSQL 测试通过。
- [x] Worker、Preview、Export Core、Build Worker 和 Web 类型检查与回归通过。
- [x] 浏览器级真实栈回归不拦截 API、不注入假响应，覆盖交互、反馈、分享、撤销、HTML/React 下载和校验。
- [x] 外部 Temporal、Chromium、Docker、对象存储或真实模型不可用时，审计明确记录为未验收，不伪造通过。

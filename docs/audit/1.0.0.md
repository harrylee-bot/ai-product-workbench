## 功能说明

用户在线输入需求，系统从本地 `knowledge-vault/`、项目数据库知识库和本地 `storage/` 检索授权知识，生成需求文档与原型。需求文档支持在线预览、编辑、发布、Word/PDF 下载；原型支持固定版本预览、分享和撤销分享。定稿可以写入项目知识库，供后续生成引用。

当前版本保留项目权限、固定版本发布、分享撤销、导出任务幂等、草稿保存、原型交互状态和知识引用证据。知识资产、可执行测试、数据库迁移及协议版本保留，不同步到外部知识库。

## P0 级问题清单（必须立即修复）

### 后端 P0

1. **PRD 模板强制生成接口章节** ⛔
   - 位置: `requirement-document-format.ts:163`
   - 影响: 与需求"PRD 不包含接口信息"直接冲突
   - 修复: 删除接口章节或标记为可选

2. **只有 user/admin 两种角色** ⛔
   - 位置: `schema.prisma:10`
   - 影响: 无法实现产品/开发/用户三级权限
   - 修复: 添加 `product` 和 `developer` 枚举值

3. **分享链接允许游客访问** ⛔
   - 位置: `share.controller.ts:40`
   - 影响: 与需求"不支持游客访问"直接冲突
   - 修复: 添加 `@UseGuards(JwtAuthGuard)`

4. **缺少评论系统** ⛔
   - 位置: `schema.prisma` (无 Comment 模型)
   - 影响: 开发/用户无法评论
   - 修复: 创建 Comment 模型和 API

5. **缺少技术文档生成** ⛔
   - 位置: 全局
   - 影响: 开发者无法生成技术文档
   - 修复: 创建 TechnicalDocument 模型 + DeerFlow action

6. **缺少多用户审批工作流** ⛔
   - 位置: `requirement-document.service.ts:225`
   - 影响: 无法实现"所有人确认后"逻辑
   - 修复: 添加审批表和状态机

### 前端 P0

7. **分享功能 UI 完全缺失** ⛔
   - 位置: 无 `/app/share/[token]/page.tsx`
   - 影响: 分享链接返回 404，功能完全不可用
   - 修复: 创建分享页路由 + 分享按钮 UI

8. **角色权限 UI 缺失** ⛔
   - 位置: `lib/auth/nest-auth.tsx`
   - 影响: 所有用户看到相同界面
   - 修复: 实现角色控制组件

9. **评论 UI 完全缺失** ⛔
   - 位置: 全局
   - 影响: 无法评论
   - 修复: 创建评论组件

10. **审批工作流 UI 缺失** ⛔
    - 位置: 全局
    - 影响: 无法多人确认
    - 修复: 添加确认按钮和状态展示

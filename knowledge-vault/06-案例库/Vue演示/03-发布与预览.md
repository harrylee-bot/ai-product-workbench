## 保存、审核、版本和发布

工作台均有约450ms自动保存；变更签名排除 version/updatedAt，界面保存状态不代表服务器持久化完成。第三包 store 采用按活动ID分隔的v3本地草稿和保存队列，恢复还要求同ID、同版本、时间更新、未锁定和不倒退；强制刷新清本地草稿。它属于浏览器缓存与本地模拟服务的演示持久化，不能代替真实数据库、并发和断电恢复证据。[组件保存原件](<storage/source-assets/cehuabao-local/originals/f2fee83ad3e8bf06/index.vue>)（[逐源笔记](<storage/source-assets/cehuabao-local/review/agent-2-vue/f2fee83ad3e8bf063c70cc9255b9eb742b0a286c3079b94a5dc28c6122c21b43.md>)）；[第三分区活动store审读](<storage/source-assets/cehuabao-local/review/agent-3-wechat-code/8e23504d333caa6a5bf0a7e510a4010a4a768ba0a1372ced987d980641cc03aa.md>)。

早两包人工确认先乐观勾选、保存失败回滚；提交仅活动ID与固定审核名，无显式当前版本/幂等键。第三包单项确认调用服务并带版本，成功后才勾选；提交先保存，取返回版本，以活动ID+版本建立幂等意图，再调用提交审核。结果不确定的网络失败保留键，确定失败清键，编辑/新版本形成新意图；组件局部键不承诺刷新后保留。

审核页的七项前端检查是：日期存在且先后顺序正确、终端非空、素材非空、热点矩形正且不越界、权益有库存且有效期覆盖活动、派单已配置且为 nearest 或已核验、表单有标题且手机号启用/必填。热点检查没有验证 action；早包却宣称动作有效，素材非空也曾宣称内容安全。第三包将素材强断言改成完整性及预览核对，但审核进度前四项仍固定 done，不能作为真实已审证据。[首包审核原件](<storage/source-assets/cehuabao-local/originals/8557e80cad0a4405/index.vue>)（[逐源笔记](<storage/source-assets/cehuabao-local/review/agent-2-vue/8557e80cad0a440545aa3b2c89efae0aa0658a9ae0e1cf3301276a63a07cd2b4.md>)）；[第二包审核原件](<storage/source-assets/cehuabao-local/originals/967c18f8486b1571/index.vue>)（[逐源笔记](<storage/source-assets/cehuabao-local/review/agent-2-vue/967c18f8486b157149aec05a50bf7cd74dc67a97d123512930f888b1c86b8a78.md>)）；[第三包审核原件](<storage/source-assets/cehuabao-local/originals/376ede196e48ed60/index.vue>)（[逐源笔记](<storage/source-assets/cehuabao-local/review/agent-2-vue/376ede196e48ed6057db208744f52f97cbf48968545750b3dbc3cda6718f992e.md>)）。

第三包 approve/reject 显式携带审批ID、活动版本和幂等键；拒因4–200字，意图签名包含拒因，未知失败保键。批准成功还核对当前审批未切换；驳回后留在审核身份刷新队列。界面“已上线”依据接口返回，并未请求真实公开H5验证。备用审核页只有静态四勾、approve(id)和成功弹窗，缺少这些约束，不能混用。[完整审核原件](<storage/source-assets/cehuabao-local/originals/376ede196e48ed60/index.vue>)（[逐源笔记](<storage/source-assets/cehuabao-local/review/agent-2-vue/376ede196e48ed6057db208744f52f97cbf48968545750b3dbc3cda6718f992e.md>)）；[备用审核原件](<storage/source-assets/cehuabao-local/originals/295e05a1f87904ca/index 2.vue>)（[逐源笔记](<storage/source-assets/cehuabao-local/review/agent-2-vue/295e05a1f87904ca32c53879f573b662ebc6e46a1a6bc300d0634f5239e01bb3.md>)）；[第三分区API契约审读](<storage/source-assets/cehuabao-local/review/agent-3-wechat-code/7ff3eb006c30bebd2631b6ff2469eb401df2be4620b5f6ed7d087c78cba572a8.md>)。

第三分区新版 Node 模拟服务静态审读可支持“原型里实现了运营/审核角色、不可自己审批、四项确认、同版本、动作幂等、快照和本地JSON持久化”等表述；正式发布、外部审批、真实派单/发券/扣库存均无本次执行证据。其幂等重放先于锁定/版本检查，允许终态重放同结果，应与“每次重新执行”区分。[模拟服务审核与发布审读](<storage/source-assets/cehuabao-local/review/agent-3-wechat-code/8b92bbe349b4a9ceb7ad6edf156a6d2369850a2d43da7ecafdde9d1518955ff2.md>)。
## H5预览、预约和结果

Web普通 PhonePreview 是DOM模拟画面，并非真实H5 iframe。早两版每次拖动都向父组件发更新；第三包用 pointerId，移动只改临时矩形，pointerup有变化才提交一次，pointercancel丢弃本地变更。H5真正预览页仍在 move 时实时发更新，cancel不会撤回先前发出的值，两处交互不能视为完全一致。[早包Web预览原件](<storage/source-assets/cehuabao-local/originals/c1fdb01f587b3918/PhonePreview.vue>)（[逐源笔记](<storage/source-assets/cehuabao-local/review/agent-2-vue/c1fdb01f587b3918a72b56e405dbb898d23a81328dc75f7936a65cbe01df5697.md>)）；[第三包Web预览原件](<storage/source-assets/cehuabao-local/originals/c4f39daaae574dde/PhonePreview.vue>)（[逐源笔记](<storage/source-assets/cehuabao-local/review/agent-2-vue/c4f39daaae574dde40ddd221b42fef05a289cdb18bde1df21c6981608dcef88e.md>)）；[第三包H5预览原件](<storage/source-assets/cehuabao-local/originals/274068122088953c/index.vue>)（[逐源笔记](<storage/source-assets/cehuabao-local/review/agent-2-vue/274068122088953c17d4d9e5e3e1fb09869ed929001d7f2df3123d5f1dd53a3c.md>)）。

H5 preview=1约800ms轮询，可见时运行、隐藏/卸载停止。早包 postMessage 向*发，接收只检查消息类型与活动ID；第三包用 document.referrer 解析父origin，要求 event.source=parent、origin匹配并验证热点存在，发送也指定父origin。它是当前嵌入关系检查，并非固定受信域白名单。401/403会停止轮询并提示，其他错误可保留旧页并显示同步中断。普通页面按 PUBLISHED 显示“进行中”和允许预约，组件自身未查日期；最终访问权限和日期仍由配对服务决定。[早包H5首页原件](<storage/source-assets/cehuabao-local/originals/f06fb44c499ed19f/index.vue>)（[逐源笔记](<storage/source-assets/cehuabao-local/review/agent-2-vue/f06fb44c499ed19f19e985912d147bc8a69a5eff01bede701e25d04e9e9d0fda.md>)）；[第二包H5首页原件](<storage/source-assets/cehuabao-local/originals/0e29646d48df7200/index.vue>)（[逐源笔记](<storage/source-assets/cehuabao-local/review/agent-2-vue/0e29646d48df7200b12e7ba83eed477958c231cbc920738ee2c9bee4ff4e752f.md>)）；[第三包H5首页原件](<storage/source-assets/cehuabao-local/originals/274068122088953c/index.vue>)（[逐源笔记](<storage/source-assets/cehuabao-local/review/agent-2-vue/274068122088953c17d4d9e5e3e1fb09869ed929001d7f2df3123d5f1dd53a3c.md>)）。

早两包预约使用固定广州门店与终端候选；提交只靠本页 submitting 防重复，无显式幂等键。结果页直接信URL的权益、门店、模式，固定显示成功及联系承诺，不能用作真实办理凭证。[早包预约原件](<storage/source-assets/cehuabao-local/originals/b87f3348fa4ab65e/index.vue>)（[逐源笔记](<storage/source-assets/cehuabao-local/review/agent-2-vue/b87f3348fa4ab65ee31ad17fb602dc5c77d450716dad6d0cc25286aef35a1b09.md>)）；[第二包预约原件](<storage/source-assets/cehuabao-local/originals/3260136273d91285/index.vue>)（[逐源笔记](<storage/source-assets/cehuabao-local/review/agent-2-vue/3260136273d912854158c09d33dc4ba52452efde06b6cc346675ead240ad75dc.md>)）；[旧结果页原件](<storage/source-assets/cehuabao-local/originals/d57d3ef655ea380a/index.vue>)（[逐源笔记](<storage/source-assets/cehuabao-local/review/agent-2-vue/d57d3ef655ea380ac4d1e6abaa18d2622a6c0d8c5994f94fd1baa0aa7ca23a9f.md>)）。

第三包预约强制按非预览读取，门店来自 activity.stores、终端只取活动终端；仅发送启用字段trim和协议同意。生成本页提交键，失败复用，编辑或同意状态改变清键，刷新不保留；成功要求 leadId 与 receiptToken，保存回执/导航失败后只重开结果，不再次留资。手机号启用时必须有效，即使字段标成非必填仍拒绝空值。[第三包预约原件](<storage/source-assets/cehuabao-local/originals/1295d9d3fcd6e68a/index.vue>)（[逐源笔记](<storage/source-assets/cehuabao-local/review/agent-2-vue/1295d9d3fcd6e68af7e00f8c6799ef835e5280e0668147ad1c80f99cf8954435.md>)）。

第三包结果页按活动ID、leadId和本地回执查询，缺回执/不匹配明确失败，不再信URL权益/门店；查询参数只含ID，不带回执。回执工具优先sessionStorage，异常回退uni持久存储，因此不能统一称只在页面会话有效。结果里的“派单中/等待门店确认”仍按派单模式推导，“1个工作日联系”“门店确认后发奖”为静态承诺，未接实际履约状态。[第三包结果原件](<storage/source-assets/cehuabao-local/originals/894f510482f8ce5f/index.vue>)（[逐源笔记](<storage/source-assets/cehuabao-local/review/agent-2-vue/894f510482f8ce5f70c111bee6f37318af34de411fd7880d43ebf7944d430697.md>)）；[回执存储审读](<storage/source-assets/cehuabao-local/review/agent-3-wechat-code/e18223bbfa55a515971ae9d0e5f50ffb04b9edd642f153cb8fec46ec6817bcab.md>)。

配套新版 Node 模拟服务实现公开字段DTO、活动日期/隐私/字段/门店/终端检查、留资幂等及凭证校验；结果DTO不给表单隐私，但仍仅生成模拟派单与权益快照。另两份领导演示HTML共享的离线H5适配器使用 localStorage，忽略 Idempotency-Key、不验证字段/隐私/门店/终端/日期，结果凭证相等即返回整条lead含原表单。不能将 Node 的约束套到离线演示上，也不能只据 Vue 前端调用认定服务闭合。[Node留资审读](<storage/source-assets/cehuabao-local/review/agent-3-wechat-code/8b92bbe349b4a9ceb7ad6edf156a6d2369850a2d43da7ecafdde9d1518955ff2.md>)；[领导演示离线适配器审读](<storage/source-assets/cehuabao-local/review/agent-3-wechat-code/asset-eed78a6d65d08c22f996c7ce1e53293934e4103b288a38a205ad7fdc2bbb9a08.md>)。

# 业务增量规则

## 先保留

- 原活动类型和模板入口；
- 当前活动配置步骤；
- 当前区域和角色权限；
- 当前审核、发布和下架状态；
- 当前报表关键指标和归因字段；
- 当前页面的导航、布局和操作习惯。

## 再增加

| 增量类型 | 必须补充 |
| --- | --- |
| 新字段 | 数据来源、默认值、必填条件、权限、历史数据兼容 |
| 新状态 | 进入条件、退出条件、操作人、失败原因、可回退动作 |
| 新筛选 | 范围、默认值、空态、分页、导出是否同步 |
| 新奖品 | 资格、库存、发放、失败、补偿和对账 |
| 新渠道 | 编码、跳转、绑定、失效、归因和报表 |
| 新素材 | 上传、审核、引用、下架和版本影响 |
| 新接口 | 请求字段、回执、重试、超时、幂等和降级 |

## 评审结果

每个增量需求输出：

- 复用的现有模板或模块；
- 新增的对象、字段和状态；
- 影响的角色和数据范围；
- 兼容旧活动的策略；
- 原型需要新增或调整的页面；
- 验收和回滚条件。

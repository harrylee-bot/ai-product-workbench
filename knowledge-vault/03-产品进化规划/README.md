# 产品进化规划

## 判断顺序

1. 先判断需求属于现有模板、现有活动类型还是新能力。
2. 优先复用活动创建、审核发布、素材、奖品、渠道和报表能力。
3. 只在现有对象无法表达时增加字段、状态或模块。
4. 跨业务共性沉淀为平台能力，区域差异保留在模板或配置层。
5. 有资损、敏感数据或外部接口影响时先补风险和验收。

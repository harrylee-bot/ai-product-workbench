# 产品进化规划

本目录回答“产品下一步怎么演进”。AI 不能把每个需求都当成孤立页面，要判断它是历史业务增量、能力平台化、风险治理补齐，还是新产品创新。

## 判断维度

| 类型 | 识别信号 | 产出策略 |
| --- | --- | --- |
| 历史业务增量 | 优化、新增字段、新增开关、某省需求、已有模板、已有页面。 | 继承原对象、流程、页面和状态，只增量补变化。 |
| 能力平台化 | 多省、多活动、多模板重复出现同类需求。 | 抽象成配置能力、模板能力、规则能力或报表口径。 |
| 风险治理补齐 | 涉及奖品、券、库存、核销、外链、导出、权限、日志。 | 优先补资损、安全、审计、回滚和验收。 |
| 新产品创新 | 新角色、新工作台、新 AI 能力、新跨模块闭环。 | 放回产品架构，说明复用能力和新增对象。 |

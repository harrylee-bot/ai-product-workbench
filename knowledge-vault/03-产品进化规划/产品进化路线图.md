# 产品进化路线图

| 方向 | 当前基础 | 进化重点 |
| --- | --- | --- |
| 模板平台化 | 抽奖、商机预约、资费订购、企微、分享裂变等模板 | 统一模板元数据、字段校验和版本管理 |
| 配置低代码化 | 页面、规则、奖品和渠道分步配置 | 提供可复用区块、默认值和配置校验 |
| 资产平台化 | 本地上传、素材库、专题、标签、AI 编辑 | 统一资产版本、审核、引用影响和下架处理 |
| 渠道可追踪 | 活动码、短链、二维码、运营位、发展人 | 统一参数、绑定关系、失效和归因口径 |
| 权益可治理 | 抽奖、奖品、券、流量包和发奖 | 统一库存、幂等、补偿、核销和对账 |
| 数据可复盘 | 活动、加粉、订单、商机和区域报表 | 统一事件模型、指标口径和权限导出 |
| AI 辅助 | AI 搜索、推荐、编辑和内容草稿 | 以案例、素材和模板为受控上下文，保留人工确认 |

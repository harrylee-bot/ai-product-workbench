# 产品进化路线图

## 总体路线

```text
活动配置工具
  → 模板化活动平台
  → 营销资产与活动能力平台
  → 数据复盘与归因平台
  → AI 辅助营销 Copilot
```

## 能力演进

| 能力 | 当前基础 | 下一步方向 |
| --- | --- | --- |
| 活动发布 | 模板选择、活动配置、审核发布、报表。 | 活动方案工作台、模板推荐、差异校验、复制复用、版本管理。 |
| 素材库 | 素材管理、专题、标签、手机端、活动联动。 | 营销资产中台、引用影响分析、AI 搜索、质量评分、素材自动适配。 |
| 奖品权益 | 奖品配置、库存、概率、核销、对账。 | 权益风控引擎、统一资格、库存锁、补偿、核销和资损评估。 |
| 渠道归因 | 渠道编码、运营位、一人一码、短链、企微。 | 统一归因模型、人员绑定、失效机制、渠道效果对比。 |
| 数据报表 | 活动报表、导出、数字大屏、运营统计。 | 数据洞察、异常提醒、模板效果分析、运营建议。 |
| AI 助手 | 案例复用、Dify 工作流、长图/文案生成。 | 营销活动 Copilot，支持方案生成、配置建议、原型生成和复盘优化。 |

## 判断优先级

1. 先补齐风险和闭环：奖品、导出、权限、审核、日志、回滚。
2. 再抽象配置能力：多省、多模板、多活动重复需求优先平台化。
3. 再提升效率：素材复用、模板推荐、案例复制、AI 生成。
4. 最后做智能优化：基于报表和历史案例给出运营建议。

# 活动发布与模板配置

## 业务定位

活动发布与模板配置是平台主线能力。它把省份或运营提出的营销诉求，转化为可配置、可预览、可审核、可发布、可统计的线上活动。

## 核心对象

| 对象 | 说明 |
| --- | --- |
| 活动 | 活动编码、名称、类型、时间、省份、状态、是否测试、活动集。 |
| 模板 | 活动类型和页面结构的复用骨架。 |
| 配置项 | 基础信息、页面内容、参与规则、奖品权益、渠道参数。 |
| 预览 | 预览二维码、预览链接、配置校验结果。 |
| 审核任务 | 提交、通过、驳回、修改后再提交。 |
| 发布版本 | 线上版本、下线、回滚和历史记录。 |

## 主流程

```text
选择活动类型/模板
  ↓
配置活动基础信息
  ↓
配置规则、页面、奖品、渠道
  ↓
生成预览并校验
  ↓
提交审核
  ↓
发布上线
  ↓
查看报表并复盘
```

## 字段与配置

- 基础信息：活动名称、活动时间、省份、活动集、是否测试活动、活动规则。
- 页面配置：标题、Banner、背景图、按钮文案、规则说明、跳转链接。
- 参与规则：登录方式、参与条件、参与次数、中奖次数、目标用户。
- 发布控制：草稿、预览、待审核、审核通过、已发布、已下线、已回滚。
- 数据配置：是否计入统计、渠道编码、运营位编码、报表字段。

## 状态与异常

- 草稿：可编辑，不能影响线上。
- 预览：配置完整后生成预览，必须展示校验失败原因。
- 待审核：关键字段冻结，驳回后回到草稿。
- 已发布：线上生效，需要版本记录。
- 已下线：停止访问，保留数据。
- 异常：模板不匹配、活动时间非法、素材缺失、奖品库存不足、渠道参数缺失、发布失败。

## PRD 重点

- 明确活动类型和模板适配规则。
- 明确本期新增的是字段、模板、流程、状态还是报表能力。
- 明确对草稿、待审核、已发布、已下线活动的影响。
- 明确审核、发布、下线、回滚和操作日志。
- 明确测试活动与正式活动的数据统计差异。

## 原型重点

- 活动列表：状态、筛选、我的活动、活动编码、活动类型。
- 模板选择页：模板筛选、模板预览、适用场景。
- 配置页：字段分组、必填校验、默认值、实时预览。
- 审核页：提交记录、变更摘要、通过/驳回。
- 发布页：发布确认、发布失败、下线和回滚。
- 报表入口：活动数据、渠道数据、导出状态。

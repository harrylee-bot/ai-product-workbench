# 活动发布与模板配置

## 活动创建

活动创建的通用步骤是：

1. 进入“极速活动发布 -> 新建活动”；
2. 按业务选择活动类型和模板；
3. 配置页面、活动信息、规则、分享、奖品、表单或楼层；
4. 保存并预览；
5. 填写活动方案和前置审批信息；
6. 提交同级审核；
7. 审核通过后发布。

原始用户手册明确的活动类型包括资费订购、海报、问卷、抽奖、商机预约、聚合和答题；具体模板会随业务和区域扩展。

## 活动信息

| 配置区 | 字段 |
| --- | --- |
| 基础信息 | 是否测试活动、活动名称、活动标题、业务类型、活动集 |
| 时间 | 活动开始时间、截止时间 |
| 范围 | 适用集团/省份/地市、用户范围、登录方式 |
| 参与 | 总次数、按天/周/月次数、白名单、目标用户 |
| 渠道 | 加载渠道、活动编码、发展人编码、运营位编码 |
| 内容 | 活动规则、分享文案、活动方案、证明文件 |

活动名称在多份配置手册中要求不超过 15 字；实施时应以具体模板校验规则为准。

## 页面配置

常见页面资产包括：

- Banner、背景图、背景颜色；
- 分享海报和悬浮按钮；
- 抽奖区、权益区、礼包区、活动规则区；
- 标题、按钮、奖品背景和轮播区域；
- 广告位图片及跳转链接；
- 门店、打卡、记录、九宫格和抽奖按钮。

图片通常支持本地上传或从素材库选择；未配置时使用模板默认资源，清除默认资源后部分区块可以为空，但参与按钮、打卡按钮、抽奖按钮等关键操作入口必须保留。

## 审核与发布

- 预览链接用于发布前验证，可配合白名单访问。
- 长链接、短链接和二维码在正式发布后作为活动传播入口。
- 提交审核需要填写相应信息，并上传活动方案或前置审批证明文件。
- 审核通过后必须执行“发布”，状态才变为“已上架”。
- 已上架活动可以下架；下架支持立即下架或预约下架。
- 已下架活动可以重新上架，重新上架进入活动编辑页面。
- 活动可以复制，复制成功后生成新的可编辑活动。

## PRD 与原型重点

- 活动类型和模板的选择结果；
- 三步或多步配置导航的当前步骤；
- 页面默认素材、清除默认素材和必填操作按钮；
- 预览、白名单、二维码和正式链接的差异；
- 审核中、审核通过、已上架、已下架和拒绝状态；
- 每个状态下用户可执行的动作。

# AI营销助手与案例库

## 输入

- 业务目标、活动类型和区域；
- 用户触达渠道；
- 活动模板、历史案例和素材专题；
- 文案、页面或海报生成意图；
- 奖品、渠道、门店和时间约束。

## 处理

1. 根据活动类型和业务目标检索相关案例。
2. 根据文字意图搜索或推荐素材。
3. 结合模板和素材生成页面、文案或活动方案草稿。
4. 把生成内容拆成可编辑字段。
5. 由业务人员确认、修改并提交审核。

## 边界

- AI 只能生成草稿，不能跳过人工确认、权限和审核。
- 不能凭空补写奖品库存、真实接口、生产链接或审批结果。
- 生成结果需要标记引用的案例、素材和待确认假设。
- 涉及敏感用户数据、真实账号或生产配置时必须停止自动生成。

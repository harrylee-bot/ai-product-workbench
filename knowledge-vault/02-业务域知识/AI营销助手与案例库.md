# AI营销助手与案例库

## 业务定位

AI 营销助手把历史案例、素材资产、用户意图和外部工作流组合起来，辅助生成营销方案、文案、长图、页面建议和活动配置建议。它不是直接替代运营，而是降低策划和配置成本。

## 核心对象

| 对象 | 说明 |
| --- | --- |
| 案例 | 历史营销活动、终端长图、模板、业务流程。 |
| 用户意图 | 活动目标、终端、受众、省份、权益、渠道。 |
| AI 生成任务 | 输入、模型/工作流、步骤、状态、结果、失败原因。 |
| 工作流 | Dify 或 OpenAI-compatible 能力的输入输出 schema。 |
| 生成结果 | 长图、文案、活动方案、素材建议、配置建议。 |
| 人工确认 | 预览、编辑、确认发布、回退模板。 |

## 主流程

```text
选择案例或输入需求
  ↓
识别营销目标和业务域
  ↓
补齐终端、素材、权益和渠道
  ↓
调用 AI 工作流生成
  ↓
展示步骤和结果预览
  ↓
人工编辑确认
  ↓
进入活动配置或素材发布
```

## 工作流边界

- 必须明确输入 schema、输出 schema、超时、失败码和回退策略。
- 不能凭空编造资费、权益、活动规则或合规提示。
- 生成内容涉及权益、资费、营销话术时，需要审核和追溯。
- Dify/外部工作流是能力层，业务用户只感知生成过程、预览结果和确认发布。

## PRD 重点

- 用户从哪里进入 AI 助手：案例库、素材库、活动发布、自然语言输入。
- AI 生成任务的状态：待生成、生成中、成功、失败、人工编辑、已确认。
- 来源案例和知识依据如何展示。
- 失败时如何回退到模板或人工编辑。
- 生成结果如何进入活动、素材或报表复盘。

## 原型重点

- 生成工作台：输入需求、选择案例、选择终端或素材。
- 生成步骤：理解目标、选择素材、生成内容、校验、预览。
- 结果预览：文案、长图、页面、配置建议。
- 人工确认：编辑、重新生成、确认发布、回退模板。
- 失败态：超时、工作流失败、内容不合规、缺少素材。

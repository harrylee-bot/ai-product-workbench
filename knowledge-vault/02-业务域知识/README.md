## 统一拆解方式

每个业务域都按以下顺序整理：

1. 业务目标和使用角色；
2. 核心对象和字段；
3. 后台配置流程；
4. 用户参与或运营执行流程；
5. 状态、异常和边界；
6. 数据与权限；
7. PRD、原型和验收重点；
8. 原始文件来源。

# 数据报表与渠道归因

## 业务定位

数据报表与渠道归因用于复盘活动效果，回答“谁投放、从哪来、带来多少访问、领取、预约、订单和核销”。它是活动闭环的最后一环，也是下一轮 AI 生成和模板优化的输入。

## 核心对象

| 对象 | 说明 |
| --- | --- |
| 指标 | PV、UV、订单量、领取量、发券成功量、预约量、核销量、转化率。 |
| 筛选条件 | 时间、活动、活动编码、活动状态、省份、渠道、运营位、活动集。 |
| 渠道码 | 渠道编码、运营位编码、活动码、一人一码、短链。 |
| 导出任务 | 导出条件、字段、权限、脱敏、导出人、导出时间。 |
| 大屏视图 | 平台使用、区域分布、趋势、TOP 活动、转化漏斗。 |

## 报表规则

- 报表导出必须与当前筛选条件一致。
- 测试活动是否计入统计必须明确。
- 省份、组织、活动集、角色决定数据可见范围。
- 涉及用户、订单、号码、商机时必须脱敏并记录导出日志。
- 数据延迟、更新时间和统计口径必须在 PRD 中写清。

## 渠道归因规则

- 活动链接需要携带活动编码、渠道编码、运营位编码等参数。
- 一人一码必须明确生成主体、绑定对象、失效机制和重复生成处理。
- 短链和企微链路必须明确跳转目标、白名单和失败提示。
- 渠道数据要能回看到活动、人员、省份和订单。

## PRD 重点

- 指标定义和计算口径。
- 筛选项和默认查询范围。
- 明细字段、导出字段和脱敏规则。
- 权限边界和越权提示。
- 导出任务状态、失败重试和日志。

## 原型重点

- 报表筛选区：时间、活动、状态、省份、渠道。
- 指标卡：核心指标和更新时间。
- 图表：趋势、漏斗、TOP 榜、区域分布。
- 明细表：字段、分页、排序、导出。
- 异常态：无数据、无权限、导出中、导出失败、数据延迟。

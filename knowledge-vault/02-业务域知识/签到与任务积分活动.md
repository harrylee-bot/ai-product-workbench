# 签到与任务积分活动

## 活动结构

CityWalk 类原始模板展示了签到/打卡和门店/渠道的组合：

- 背景海报图；
- 打卡按钮和打卡记录按钮；
- 支持活动的门店数量；
- 门店渠道编码；
- 九宫格背景、抽奖按钮和奖品背景；
- 轮播展示区域；
- 适用省市、登录方式、用户范围；
- 总参与次数或按周期限制。

## 参与流程

`进入活动 -> 登录/资格校验 -> 选择或到达门店 -> 完成打卡 -> 写入打卡记录 -> 获得抽奖次数/积分 -> 抽奖或兑换 -> 报表复盘`

## 规则字段

| 规则 | 需要明确 |
| --- | --- |
| 时间 | 活动开始/结束、业务日期和时区 |
| 次数 | 每日、每周、每月或总次数 |
| 门店 | 门店数量、门店编码、有效范围 |
| 任务 | 任务类型、完成条件、完成证明 |
| 积分 | 获得值、上限、账本和消耗 |
| 奖励 | 抽奖次数、奖品、库存和发放 |
| 异常 | 重复打卡、无资格、定位/门店不匹配、接口失败 |

## 页面状态

前台至少表达首次进入、可打卡、已打卡、记录查看、无资格、未登录、活动未开始、活动已结束、奖励发放中和发放失败。

后台至少提供活动基础设置、规则设置、门店/渠道、奖励、页面素材、预览审核和数据报表。

## 贵州经验与分享加抽的版本边界

广西养成原型另展示签到累计/连续周期、浏览时长、解锁日期、经验及奖券、订购奖励和守护计划。经验 100/200/300、红包 0.2/0.5/1/5 元等是示例配置，部分行不完整；发布后能否修改、前置活动完成、频次及等级计算未在原型动作中实现，不作为已确认通用算法。来源见 [广西逐页归纳](<storage/source-assets/cehuabao-local/review/prototype-interaction-guangxi-logs-topic-notes.md>)。

贵州 2026 年 7 月签到资料将签到经验、图片任务经验、兑奖门槛和成功订单分别处理。每 100 经验对应 2GB 是示例进度，不表示每次已经发放流量；达门槛后按配置跳省订购页或其他产品链路，领取状态需与订单结果核对。月初重置签到及经验，图片任务每月一次的口径只适用于该稿。

同日技术稿的正文上限默认 1 次且允许非负，技术段却默认 5 次、最小 1 次；图片可清除与保存必填也冲突。7 月 31 日操作手册补充任务标题 16 字、活动名 15 字、正整数经验、目标用户四种来源和同级不得自审，但不能据手册自动消除上述冲突。具体默认值、月度幂等和任务完成条件保留待裁决项。

5 月分享加抽稿的详细规则要求好友打开带分享标识的链接并登录，排除本人，同一好友同周期只算一次；按天频次次日旧链失效。同稿首段却有生成链接即奖励、最多 1 次的相反口径，后续删掉部分矛盾的稿仍与可配上限示例不同。不得把“点击复制”直接当有效助力，也不把任一示例次数升级为全平台规则。

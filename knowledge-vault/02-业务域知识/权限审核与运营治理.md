# 权限审核与运营治理

## 业务定位

权限审核与运营治理保障平台可控、可追溯、可回滚。它是活动、素材、奖品、报表、外链和 AI 生成的横切能力。

## 核心对象

| 对象 | 说明 |
| --- | --- |
| 角色 | 集团、平台、省、市、区、一线运营、审核人员。 |
| 权限点 | 创建、编辑、审核、发布、下线、导出、查看。 |
| 审核任务 | 待审核、通过、驳回、撤回、再次提交。 |
| 操作日志 | 操作人、对象、动作、时间、结果、变更前后值。 |
| 治理规则 | 标签、专题、素材、活动码、一人一码、报表导出。 |

## 审核流程

```text
提交变更
  ↓
生成审核任务
  ↓
展示变更对象和影响范围
  ↓
审核通过或驳回
  ↓
通过后发布/生效
  ↓
记录操作日志和版本
```

## 必备规则

- 高风险操作必须展示变更前后值和影响范围。
- 驳回后再次提交不能覆盖历史审核记录。
- 报表导出必须绑定角色、省份、组织和导出日志。
- 素材、模板、活动码、一人一码必须有启停、历史兼容和失效机制。
- 后端必须校验权限，不能只靠前端隐藏入口。

## PRD 重点

- 角色矩阵和数据范围。
- 哪些动作需要审核，哪些动作只需要日志。
- 审核任务字段、状态流转、驳回再提交规则。
- 操作日志字段和保留范围。
- 越权、无权限、审核冲突和并发修改处理。

## 原型重点

- 权限矩阵或角色配置页。
- 审核列表：状态、提交人、对象、时间、操作。
- 审核详情：变更前后值、影响范围、驳回原因。
- 操作日志：筛选、明细、导出权限。
- 无权限状态和高风险二次确认弹窗。

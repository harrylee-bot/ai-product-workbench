# 素材库与营销资产

## 业务定位

素材库不是简单文件夹，而是活动发布、AI 生成、专题运营和一线营销复用的资产中台。它要解决素材查找、审核、复用、引用影响和跨端制作问题。

## 核心对象

| 对象 | 说明 |
| --- | --- |
| 素材 | 图片、海报、长图、Banner、文案、模板内容。 |
| 标签 | 搜索、筛选、推荐和归类的基础。 |
| 专题 | 按营销场景组织素材。 |
| 模板 | 可复用页面或海报骨架。 |
| 广告位 | 素材投放位置和跳转入口。 |
| 审核任务 | 素材提交、审核、驳回、修改记录。 |
| 引用关系 | 素材被哪些活动、专题、模板使用。 |

## 主流程

```text
上传/生成素材
  ↓
填写分类、标签、专题、适用范围
  ↓
审核
  ↓
上架/启用
  ↓
在活动或 AI 生成中引用
  ↓
统计使用效果
  ↓
替换/下线/归档
```

## 关键规则

- 标签、专题、分类必须统一命名，否则会影响搜索、筛选和推荐。
- 素材被活动引用后，下线、替换、删除必须说明对草稿、待审核、已发布活动的影响。
- 手机端素材和 PC 端素材需要统一字段和状态。
- 素材审核要保留提交人、审核人、驳回原因和修改记录。
- AI 生成素材必须保留来源案例、输入意图、生成结果和人工确认。

## PRD 重点

- 素材生命周期：草稿、待审核、已上架、已下架、已归档。
- 引用影响：被哪些活动、专题、广告位、模板引用。
- 搜索筛选：关键词、标签、专题、分类、状态、权限。
- 历史兼容：旧素材标签、旧专题、旧活动引用怎么处理。
- 数据复盘：使用次数、引用活动数、转化效果、导出权限。

## 原型重点

- 素材列表：筛选、标签、专题、状态、引用数。
- 素材详情：预览、元数据、审核记录、引用影响。
- 素材选择器：活动配置页选择素材并回填。
- 专题/标签管理：新增、编辑、排序、启用禁用、空态。
- 异常态：无素材、无权限、素材下线、审核驳回、引用冲突。

# 号卡OAO与商机预约

## 业务定位

号卡/OAO/商机预约类需求把活动页面和线下或订单履约连接起来，核心是用户填写、资格校验、门店/套餐/发展人绑定、商机回传和转化统计。

## 核心对象

| 对象 | 说明 |
| --- | --- |
| 预约单 | 用户预约信息、预约门店、预约时间、状态。 |
| 商机单 | 商机来源、客户经理、发展人、处理状态。 |
| 门店 | 门店编码、名称、地址、可预约状态、展示开关。 |
| 套餐/号卡 | 套餐信息、入网时间、合规限制、订购状态。 |
| 订单 | 下单、支付、回传、失败状态。 |
| 渠道归因 | 活动编码、渠道编码、运营位、发展人、一人一码。 |

## 主流程

```text
用户进入活动页
  ↓
登录/授权/资格校验
  ↓
选择套餐或预约门店
  ↓
提交预约/订单/商机
  ↓
接口回传状态
  ↓
后台查看商机和报表
```

## 关键规则

- 门店展示、默认门店、门店上传开关要写清。
- 发展人、渠道编码、运营位编码要跟订单或商机绑定。
- 号卡和套餐要考虑合规提示、入网时间、身份校验和接口失败。
- 商机预约要有提交成功、重复提交、无门店、接口失败和状态回传。
- 涉及个人信息时必须脱敏、授权和留痕。

## PRD 重点

- 用户路径：进入、授权、选择、提交、结果、回访。
- 后台配置：门店、套餐、发展人、渠道参数、活动规则。
- 接口口径：提交参数、回传状态、失败码、重试策略。
- 数据统计：预约数、订单数、转化率、门店、发展人、渠道。
- 合规风险：个人信息、授权、号卡合规、越权查看。

## 原型重点

- 移动端预约页：基础信息、门店选择、套餐选择、提交按钮。
- 后台配置页：门店开关、默认门店、渠道和发展人配置。
- 状态页：提交成功、重复提交、资格不符、接口失败。
- 报表页：预约明细、商机状态、订单状态、渠道归因。

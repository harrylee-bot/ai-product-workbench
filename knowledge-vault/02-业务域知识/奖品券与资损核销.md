# 奖品券与资损核销

## 业务定位

奖品券能力负责把营销权益发给正确用户，并控制库存、重复领取、核销、对账和资损风险。涉及权益的需求必须优先读取本页。

## 核心对象

| 对象 | 说明 |
| --- | --- |
| 奖品 | 实物、券、流量包、话费、自有产品、销售品。 |
| 库存 | 总库存、可用库存、锁定库存、发放库存。 |
| 领取记录 | 用户领取、发放状态、失败原因。 |
| 核销记录 | 核销方式、核销状态、核销时间、核销门店。 |
| 对账记录 | 发放、核销、退款、失败补偿和异常差异。 |
| 资损规则 | 资格、次数、概率、防刷、黑白名单。 |

## 主流程

```text
配置奖品/券/权益
  ↓
配置库存、概率、资格、次数
  ↓
活动中展示和领取
  ↓
发放/核销/下单
  ↓
失败补偿或回滚
  ↓
对账和报表复盘
```

## 风险规则

- 抽奖必须写中奖概率、奖池、库存不足兜底和重复中奖限制。
- 券和流量包必须写领取资格、发放失败、退款/补偿和对账。
- 实物奖品必须写库存、物流或领取方式、核销方式和异常处理。
- 点击即核销类能力必须增加二次确认、误触兜底和核销日志。
- 修改已发布活动奖品规则必须说明影响范围和回滚方式。

## PRD 重点

- 奖品类型、来源、库存、资格、概率、领取次数、中奖次数。
- 发放链路、核销链路、失败补偿、退款和对账。
- 防刷、黑白名单、重复领取、接口幂等。
- 与活动状态、用户资格、报表口径的关系。
- 历史活动、草稿活动和已发布活动的兼容。
- 不在 PRD 中输出资损表、资损风险评估表或资损点检表；PRD 只保留资损风险场景、产品约束、控制点和验收口径，资损表由开发后期补填。

## 原型重点

- 奖品配置表单：类型、库存、概率、资格、发放规则。
- 库存状态：充足、低库存、已锁定、已发完。
- 前台领取态：可领取、已领取、无资格、库存不足、发放失败。
- 核销态：待核销、已核销、核销失败、已过期。
- 对账报表：发放数、核销数、失败数、补偿数、异常差异。

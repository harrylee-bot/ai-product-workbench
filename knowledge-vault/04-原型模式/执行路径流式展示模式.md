# 执行路径流式展示模式

执行路径用于让用户感知系统正在自动分析、决策和生成。它应该出现在聊天对话中，而不是作为右侧固定功能面板长期占用注意力。

## 默认形态

```text
执行路径                       已完成
约束、决策、评审、补丁预览与进化记录统一展示
```

默认收起。展开后展示每一步：

```text
1. 约束系统：命中 6 条规则
2. 决策系统：生成 3 个策略，选择平衡策略
3. Review Board：产品、UX、技术、风险、增长完成评审
4. Agent 执行：生成 PRD 与 Prototype
5. Patch Preview：待用户确认
6. Evolution：记录本次策略表现
```

## 流式状态

| 阶段 | 展示内容 |
| --- | --- |
| 意图识别 | 已识别需求类型和业务域 |
| 知识检索 | 引用了哪些知识条目 |
| 约束命中 | must_follow、prefer、avoid、warn |
| 策略生成 | 至少 3 个策略 |
| 评审选择 | Agent 评分和选中原因 |
| 产物生成 | PRD、Prototype、Patch Preview |
| 进化记录 | promote、demote、neutral |

## 交互规则

- 默认收起，减少干扰。
- 卡片状态跟随执行进度更新。
- 失败时展示明确原因和可恢复动作。
- 展开后可复制结构化日志。
- 不展示底层命令，除非用户进入管理员/调试模式。

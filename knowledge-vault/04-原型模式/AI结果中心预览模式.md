# AI 结果中心预览模式

AI 结果中心是右侧统一结果区。它不是工具面板，而是系统完成决策和生成后的结果展示中心。

## 结构

```text
AI 结果中心
  ├─ 需求结果
  │   ├─ PRD
  │   ├─ ProductDesignState 摘要
  │   └─ 验收标准
  ├─ 设计结果
  │   ├─ Prototype HTML
  │   ├─ 页面结构
  │   └─ 真实预览
  └─ 执行路径
      ├─ 命中的约束
      ├─ 生成的策略
      ├─ Agent 状态
      └─ Evolution 影响
```

## 预览原则

- PRD 以结构化中文内容展示。
- Prototype 优先展示真实 HTML 预览，代码作为辅助。
- 执行路径展示摘要，完整详情在聊天流卡片里展开。
- 用户不需要单独点击“生成 PRD”或“生成原型”。

## 标签建议

- `需求结果`
- `设计结果`
- `执行路径`

不使用：

- `PRD 工具`
- `Prototype 工具`
- `Diff 工具`
- `改写工具`

## 和聊天流的关系

聊天流负责过程感知，AI 结果中心负责最终产物预览。

- 过程看 [[04-原型模式/执行路径流式展示模式]]。
- 决策看 [[00-系统说明/三系统融合架构]]。
- 前端约束看 [[02-规则约束/UI UX UE 操作系统约束]]。

## 验收标准

- 生成 PRD 后右侧能看到“需求结果”。
- 生成 HTML 原型后右侧能看到真实页面预览。
- 右侧不展示复杂工具按钮。
- 用户能从结果中心返回聊天继续输入新意图。

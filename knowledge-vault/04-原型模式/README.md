# 原型模式

原型模式记录历史需求里反复出现的页面结构和后台配置方式。这里只记录业务系统常见页面模式。

## 关键原则

- 需求涉及活动、素材、奖品、报表或号卡模板时，应同时考虑用户端页面和后台配置端。
- 后台配置需要覆盖字段、默认值、校验、权限、状态流转和审计记录。
- 预览、二维码、审核、发布、下线、回滚和数据统计应作为完整闭环设计。
- 奖品/券/跳转/报表类需求必须展示异常态、空态和失败兜底。

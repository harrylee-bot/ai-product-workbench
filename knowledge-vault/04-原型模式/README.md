# 原型模式

原型模式记录 AI Product OS 的展示和交互规则。用户只表达意图，系统负责自动拆解、生成结果和展示路径。

## 核心条目

- [[04-原型模式/执行路径流式展示模式|执行路径流式展示模式]]
- [[04-原型模式/需求文档沉淀/配置化页面与后台模式|配置化页面与后台模式]]

## 关键原则

- PRD 和 Prototype 不独立暴露为工具按钮，而是作为 AI 结果中心的一部分自动出现。
- 执行路径应在聊天流中流式展示，默认收起，用户需要时展开查看。
- 原型预览应尽量接近真实页面，右侧或独立预览区展示 HTML 效果。
- UI 不替用户做决策；策略、约束、评审和执行由系统完成。

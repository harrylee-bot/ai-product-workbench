# 权限数据风险模型

## 角色与数据范围

| 角色 | 默认范围 | 主要能力 |
| --- | --- | --- |
| 平台管理员 | 平台全部 | 平台、角色和全局配置 |
| 集团管理员 | 平台全部 | 集团活动、模板和数据 |
| 省管理员 | 本省 | 本省活动、审核、渠道和报表 |
| 市管理员 | 本市 | 本市活动和本市数据 |
| 区管理员 | 本区县 | 区县活动和本区县数据 |
| 店长 | 本门店 | 门店活动和门店相关数据 |

平台其他权限由菜单权限控制；角色承载菜单权限，用户承载角色权限，菜单内数据再按可管理区域过滤。

## 审批规则

- 活动采用同级审批。
- 发起人不能审批自己发起的活动。
- 活动方案和前置审批证明文件可以进入审核详情供审核人下载查看。
- 审核通过后活动状态为“审核通过”，还需要执行“发布”才进入“已上架”。

## 风险分级

| 风险 | 典型对象 | 设计要求 |
| --- | --- | --- |
| 资损 | 奖品、券、流量包、话费、抽奖 | 库存、资格、幂等、发放状态、失败补偿和对账 |
| 数据 | 手机号、订单、商机、企微数据 | 最小权限、脱敏展示、导出审计和区域隔离 |
| 发布 | 生产链接、二维码、短链 | 预览白名单、审核门禁、发布状态和下架能力 |
| 渠道 | 活动码、运营位、发展人编码 | 参数校验、绑定关系、失效时间和归因口径 |
| 素材 | 未审核素材、高清下载 | 水印、审核、下载权限和使用状态 |

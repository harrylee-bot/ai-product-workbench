# 权限数据风险模型

权限、数据、风险、审核和日志是平台横切能力。它们不能只在页面里补一个入口，而要贯穿对象、流程、接口、报表和验收。

## 权限维度

| 维度 | 说明 | PRD 关注点 |
| --- | --- | --- |
| 角色 | 集团、平台、省、市、区、一线运营、审核人员、管理员。 | 每个角色能创建、查看、审核、发布、导出什么。 |
| 组织 | 集团、省、市、区县、门店、客户经理。 | 数据可见范围和操作范围。 |
| 对象 | 活动、素材、奖品、报表、审核任务、渠道码。 | 哪些对象需要权限点。 |
| 动作 | 新增、编辑、复制、提交、审核、发布、下线、导出。 | 高风险动作是否需要二次确认或审核。 |
| 数据 | 用户、手机号、订单、奖品、商机、渠道、报表明细。 | 脱敏、导出、审计和越权控制。 |

## 数据口径

| 数据类型 | 关键口径 |
| --- | --- |
| 活动数据 | 活动编码、活动状态、是否测试活动、活动时间、创建组织、活动集。 |
| 流量数据 | PV、UV、渠道、运营位、活动码、一人一码。 |
| 转化数据 | 订单、商机、预约、下单、领取、核销。 |
| 奖品数据 | 库存、中奖概率、发放状态、核销状态、对账状态。 |
| 素材数据 | 素材引用、专题、标签、审核、上下线、使用次数。 |
| 导出数据 | 导出人、导出范围、导出条件、脱敏方式、导出时间。 |

## 风险模型

| 风险类型 | 触发场景 | 必备控制 |
| --- | --- | --- |
| 资损风险 | 奖品、券、流量包、话费、抽奖、核销、补偿。 | 资格、库存锁、幂等、对账、失败补偿、回滚。 |
| 权限风险 | 报表导出、跨省查看、素材审核、活动发布。 | 角色、组织范围、后端校验、审计日志。 |
| 合规风险 | 号卡、个人信息、外链、小程序跳转、营销话术。 | 授权、脱敏、白名单、合规文案、审核记录。 |
| 发布风险 | 活动上线、模板变更、素材替换、奖品规则修改。 | 预览、审核、灰度、版本记录、下线回滚。 |
| 数据风险 | 报表口径、统计延迟、历史数据兼容。 | 口径说明、更新时间、空值策略、导出一致性。 |

## 审核与日志

- 审核记录必须包括提交人、提交时间、审核人、审核结果、驳回原因、变更对象、变更前后值。
- 操作日志必须包括操作人、对象、动作、时间、结果、失败原因、影响范围。
- 高风险操作需要二次确认，必要时进入审核。
- 发布、下线、回滚、导出、奖品变更、权限变更必须留痕。

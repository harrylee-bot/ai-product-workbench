## 总体定位

策划宝/云溪营销活动是一套面向集团、省、市、区和一线运营的营销活动能力平台。它不是单一活动页，也不是单一素材库，而是围绕“营销活动从策划到发布再到复盘”的闭环平台。

```text
营销活动能力平台
  = 活动发布
  + 素材资产
  + 奖品权益
  + 审核发布
  + 渠道归因
  + 数据复盘
  + AI 生成
```

## AI 理解原则

- 先定位能力层，再定位核心对象。
- 活动、素材、奖品、渠道、报表、审核、AI 任务是高频核心对象。
- 草稿、预览、审核、发布、下线、回滚是默认状态链路。
- 权限、数据、风险、日志是横切能力，不属于某个单页。

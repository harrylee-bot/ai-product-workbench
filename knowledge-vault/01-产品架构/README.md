# 产品架构

策划宝/云溪营销活动平台是一套面向集团、省、市、区县、门店和运营人员的营销活动配置与发布平台。核心价值是用模板化、参数化方式完成活动自建、规则自建、多渠道触达、审核发布和数据复盘。

## 能力分层

1. 账号与组织：4A 登录、角色、组织区域和门店范围。
2. 活动工作台：活动列表、新建、编辑、复制、预览、提交审核、发布、下架和重上架。
3. 模板配置：抽奖、商机预约、资费订购、企微加粉、短链、分享裂变、签到/打卡和区域项目模板。
4. 营销资产：素材库、专题、标签、活动集、海报、Banner、背景和按钮。
5. 权益与转化：奖品、券、流量包、抽奖、核销、商机、订单和发展人编码。
6. 数据运营：活动报表、加粉数据、渠道归因、订单/商机数据和导出。
7. AI 能力：AI 搜索素材、素材推荐、素材编辑和营销活动辅助生成。

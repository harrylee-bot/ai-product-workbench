# 核心对象模型

AI 写 PRD 或原型时，必须先明确需求改变哪个对象。对象不清，字段、流程、状态和报表都会散。

## 核心对象

| 对象 | 含义 | 关键字段 | 关联对象 |
| --- | --- | --- | --- |
| 活动 Activity | 一次可配置、可发布、可统计的营销活动。 | 活动编码、活动名称、活动类型、时间、省份、活动状态、是否测试活动、活动集。 | 模板、页面、奖品、渠道、审核、报表。 |
| 模板 Template | 可复用的活动结构和配置骨架。 | 模板类型、适用场景、页面结构、配置字段、启停状态。 | 活动、页面、素材、奖品规则。 |
| 页面 Page | 用户端活动页面或后台管理页面。 | 页面名称、页面类型、组件、展示状态、入口、预览地址。 | 活动、模板、素材、配置字段。 |
| 素材 Material | 图片、海报、长图、文案、专题、广告位素材。 | 素材 ID、名称、类型、标签、专题、审核状态、引用关系。 | 活动、模板、专题、AI 生成任务。 |
| 奖品 Prize | 实物、券、流量包、自有产品、销售品等权益。 | 奖品编号、类型、库存、概率、领取资格、核销方式、订单分类。 | 活动、用户、领取记录、核销记录、报表。 |
| 渠道 Channel | 投放来源、运营位、活动码、一人一码、短链、企微人员。 | 渠道编码、运营位编码、活动码、人员、省份、失效时间。 | 活动、用户行为、订单、报表。 |
| 审核任务 AuditTask | 活动、素材、奖品、外链或高风险操作的审批记录。 | 提交人、审核人、状态、变更前后值、驳回原因、影响范围。 | 活动、素材、配置、操作日志。 |
| 报表 Report | 活动效果、订单、抽奖、商机、渠道、素材使用等统计。 | 指标口径、筛选条件、导出字段、更新时间、权限、脱敏规则。 | 活动、奖品、渠道、订单、用户行为。 |
| AI 生成任务 AIJob | 案例复用、文案/长图/活动方案生成过程。 | 输入意图、来源案例、工作流、生成状态、输出结果、确认发布。 | 案例、素材、活动、审核、发布。 |
| 用户 User | 平台账号、运营人员、审核人员或终端用户。 | 角色、组织、省份、权限、可见范围、操作记录。 | 活动、审核、报表、素材、渠道。 |

## 对象关系

```text
用户
  → 创建/审核/查看 活动
活动
  → 使用 模板
  → 引用 素材
  → 配置 奖品
  → 绑定 渠道
  → 生成 审核任务
  → 产生 报表
AI生成任务
  → 读取 案例/素材/历史数据
  → 输出 活动方案/素材/页面建议
  → 回写 活动配置或素材结果
```

## 字段设计原则

- 字段必须归属到对象，不能只说“新增字段”。
- 字段必须说明默认值、校验、展示位置、生效范围、历史数据兼容。
- 影响报表的字段必须说明统计口径和导出口径。
- 影响发布或权益的字段必须说明审核、日志和回滚。
- 影响前台展示的字段必须说明后台配置和预览联动。

## 常见误区

- 把活动字段写成页面文案，没有说明数据来源。
- 把报表字段写成列表列名，没有说明统计口径。
- 把奖品字段写成展示项，没有说明库存、资格、核销和对账。
- 把素材字段写成筛选项，没有说明标签体系和引用影响。
- 把 AI 输出写成结果卡片，没有说明输入 schema、失败兜底和人工确认。

# 核心对象模型

| 对象 | 关键字段 | 关联对象 |
| --- | --- | --- |
| 活动 | 活动名称、标题、类型、活动集、时间、状态、是否测试 | 模板、规则、页面、奖品、渠道、报表 |
| 模板 | 模板名称、活动类型、页面区块、默认素材、默认规则 | 活动、素材 |
| 页面配置 | Banner、背景、海报、按钮、规则图、权益图、跳转链接 | 活动、素材 |
| 活动规则 | 省市、用户范围、登录方式、参与次数、白名单、目标用户 | 活动、用户 |
| 奖品/权益 | 名称、图片、类型、库存、中奖/领取条件、发放状态 | 活动、用户、订单 |
| 渠道 | 活动编码、渠道编码、运营位、活动链接参数、发展人 | 活动、用户行为、商机、订单 |
| 素材 | 图片/文案/模板、专题、标签、审核状态、水印状态 | 页面、活动、AI 编辑 |
| 商机 | 用户信息、门店、套餐、发展人、处理状态、来源 | 活动、订单、渠道 |
| 报表 | 指标、筛选、明细、更新时间、导出字段 | 活动、渠道、奖品、商机 |

## 关系约束

- 活动必须绑定一个模板或明确的活动类型。
- 页面配置可以引用本地上传资产，也可以引用素材库资产。
- 活动规则决定页面是否可参与，奖品规则决定结果是否可领取。
- 渠道参数必须随活动链接进入并落到行为、商机或订单明细。
- 报表不能脱离活动、渠道和事件口径独立定义。

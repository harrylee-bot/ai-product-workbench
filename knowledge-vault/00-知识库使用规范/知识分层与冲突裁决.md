# 知识分层与冲突裁决

## 信息分层

| 层级 | 判断方式 | 使用范围 |
| --- | --- | --- |
| 平台共性 | 多份手册共同出现，且覆盖活动创建、审核、发布或权限 | 可用于平台级方案。 |
| 模板规则 | 在某个活动类型或模板手册中明确出现 | 仅用于该模板或同类模板。 |
| 区域案例 | 文件名带省、市、区域或具体项目 | 作为案例，不直接升级为全局规则。 |
| 原型表达 | RP 或 HTML 中展示的页面、字段、文案和交互 | 用于原型参考，需与文字手册交叉确认。 |
| 待确认项 | 只有截图、单个文件、模糊文字或推断 | 输出时标记待确认。 |

## 冲突裁决顺序

1. 同一模板的配置手册优先于泛平台介绍。
2. 同一文件内的字段说明优先于目录或演示页标题。
3. 同一业务在多个来源中重复出现的内容视为共性候选。
4. 区域、项目和特定活动只影响对应范围。
5. 只在 RP/HTML 中出现、手册没有文字说明的内容保留为原型表现，不推导接口合同。
6. 无法裁决时保留两个版本的来源并提出确认点。

## 引用要求

每个业务条目至少保留：

- 原始文件路径；
- 文件类型或模板名称；
- 归纳出的对象、流程、字段或状态；
- 适用范围；
- 需要验证的事项。

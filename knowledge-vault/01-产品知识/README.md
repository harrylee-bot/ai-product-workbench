## 使用规则

- 输入是模糊需求时，先看 [[01-产品知识/需求输入分类法|需求输入分类法]]。
- 输入涉及历史营销、云溪、号卡、素材、奖品、报表、安全需求时，读取 [[01-产品知识/需求文档知识库/业务域索引|业务域索引]]。
- 输入涉及 AI 营销助手、Dify、案例库和长图时，读取 [[03-案例库/需求案例库/AI营销助手案例|AI 营销助手案例]]。
- 输入涉及奖品、券、核销或资损时，读取 [[02-规则约束/需求文档沉淀/营销活动与资损约束|营销活动与资损约束]]。

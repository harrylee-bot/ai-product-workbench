# 业务域产品逻辑映射

这份映射表用于回答：某个新需求属于哪个业务域，应该复用哪个历史逻辑，原型和 PRD 要输出什么能力。

## 一、业务域到对象/流程映射

| 业务域 | 核心业务对象 | 主流程 | 异常与风控 | 典型页面 |
| --- | --- | --- | --- | --- |
| AI 营销助手 | 案例、终端、素材、模板、营销活动 | 选择案例 → 配置参数 → 生成预览 → 确认发布 → 统计复盘 | 工作流调用失败、案例失效、模型超时、素材缺失 | 前台：案例库入口、终端选择、预览；后台：模板参数、配置日志 |
| 云溪活动 / 券活动 | 活动、奖品券、商机单、核销口令 | 活动配置 → 渠道/省份策略 → 审核 → 发布 → 下线/回滚 | 奖品库存不足、核销冲突、第三方跳转失败、权限越权 | 前台：活动页、领取/核销入口；后台：活动配置、发布与回滚、报表 |
| 号卡 / OAO | 商机单、进件材料、终端任务 | 任务下发 → 渠道路由 → 进件流转 → 处理结论 | 流程阻塞、重复提交、外部接口失败 | 前台：流程状态页；后台：商机列表、处理批量、导出 |
| 素材库与长图 | 模板、素材、版本、变量 | 素材入库 → 审核合规 → 应用到场景 → 复用/回退 | 模板失效、变量缺失、版权/合规警示 | 前台：素材选择/预览；后台：素材版本、标签、替换与下线 |
| 报表与看板 | 报表配置、指标、维度、导出记录 | 指标筛选 → 预览生成 → 导出权限校验 → 下载 | 口径漂移、脱敏缺失、导出过大 | 前台：统计列表、图表、筛选器；后台：字段映射、导出审计 |

## 二、映射决策输出（AI 调用顺序）

1. 先识别业务域（AI 营销、云溪活动、号卡、素材、报表、资损）。
2. 再判断对象重用程度（活动/模板/商机/报表是否可复用）。
3. 再选取边界：历史增量 / 平台化新增 / 新产品创新。
4. 最后输出：
   - PRD 字段：业务对象、字段、状态、验收、风控。
   - 原型字段：前台页面、后台配置、异常态、发布闭环。

## 三、映射输出要求

- 同一个业务域必须先给“复用对象清单”，再给“本次新增对象清单”。
- 输出应始终保留：
  - `活动对象 / 奖品券 / 商机单 / 素材 / 报表` 任一相关对象的状态链。
  - `异常态` 与 `回滚策略`。
  - `发布后验收` 与 `责任边界`（谁确认、谁发布、谁回滚）。

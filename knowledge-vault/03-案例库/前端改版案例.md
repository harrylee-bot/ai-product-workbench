# 前端改版案例

本案例来自 AI Product Workbench 前端改造需求。目标是从“三栏工具界面”升级为“AI 操作系统界面”。

## 旧状态

- 左侧是 Projects，偏项目管理工具。
- 中间是 Chat，但执行路径和生成过程感知较弱。
- 右侧把 Constraint、Decision、Evolution、Company 等系统能力直接作为面板展示，认知负担较高。
- 顶部存在独立用户栏，空间占用较大。
- PRD 和 Prototype 的预览入口不够明确。

## 新目标

```text
左侧：最近对话 / 项目入口 / 可折叠历史
中间：唯一 AI 输入 + 聊天流 + 执行路径流式展示
右侧：AI 结果中心，统一预览 PRD、Prototype、执行摘要
```

## 关键改造

- 左侧从 Projects 改成“最近对话”，保留项目但弱化工具感。
- 左侧历史栏支持展开/收起，收起后保留图标导航。
- 用户信息移动到左下角。
- 中间保留唯一 AI 输入框。
- 多 Agent 分析处理作为聊天流中的“执行路径”卡片，默认收起。
- 右侧统一为 AI Result OS Center，展示需求结果、设计结果、执行路径。
- HTML 原型采用真实预览方式，不只显示代码。

## 设计依据

- 前端必须遵守 [[02-规则约束/UI UX UE 操作系统约束]]。
- 执行过程遵守 [[04-原型模式/执行路径流式展示模式]]。
- 结果预览遵守 [[04-原型模式/AI结果中心预览模式]]。
- 系统主流程遵守 [[00-系统说明/系统执行链路]]。

## 验收标准

- 页面文案全部中文。
- 只有一个 AI 输入入口。
- 没有工具按钮。
- 执行路径在聊天流中流式展示。
- Agent 执行状态默认收起、可展开。
- 右侧可以预览 PRD 和 Prototype。
- 用户能够理解“系统正在自动决策”，而不是“我在操作工具”。

# 历史业务增量与创新复用矩阵

这个矩阵用于快速判断：

- 同类需求应该复用到哪个历史案例；
- 哪些需求属于新增创新模式；
- 哪些项建议在 PRD 与原型阶段拆分为“已有能力扩展”和“新能力新增”。

## 维度定义

| 维度 | 重用度 | 描述 |
| --- | ---: | --- |
| 规则重合 | 0-5 | 与历史案例的流程规则相似度 |
| 对象复用 | 0-5 | 与历史对象模型（活动/奖品/商机/模板）重叠度 |
| 风险新颖度 | 0-5 | 新风控场景或新异常是否出现 |
| 发布复杂度 | 0-5 | 审核、回滚、导出、权限是否新增 |

## 应用规则

- 高重用（规则重合>=4 且对象复用>=4）：走历史业务增量。
- 中等重用（至少一项 <4）：走平台化新增。
- 低重用且风险新颖>=4：归类为新产品创新。

## 建议复用路线（按业务域）

### 活动/云溪类

- 优先看：`[[03-案例库/需求案例库/云溪营销活动案例索引|云溪营销活动案例索引]]`
- 可复用项：活动配置模板、审核门禁、发布口径。
- 典型创新：跨省差异化治理、第三方跳转模型。

### AI营销助手类

- 优先看：`[[03-案例库/需求案例库/AI营销助手案例|AI营销助手案例]]`
- 可复用项：案例入口、长图生成、终端画像、模型输出回路。
- 典型创新：多模型路由、新场景工作流。

### 号卡/OAO

- 优先看：历史号卡和 OAO 相关历史条目（见 `云溪营销活动案例索引` 各段）。
- 可复用项：商机单状态和渠道维度。
- 典型创新：新流程节点和商机单新字段联动。

### 报表与安全

- 优先看：跨活动报表导出相关案例。
- 可复用项：权限模型、字段口径、导出记录。
- 典型创新：新字段聚合、异常链路追踪。

## 与 PRD/原型的落地约束

- 历史增量：优先复用章节结构和页面状态。
- 创新类：保留 `产品进化与创新决策` 的边界说明。
- 所有复用都要写清 `已复用对象 / 新增对象 / 风险边界 / 回滚策略`。

## 快速写作参考

生成原型前可复用一句话：

> 该需求以 `历史可复用对象` 为主，`新增字段` 为辅助；
> 以历史发布闭环为基础，仅在 `权限 + 风险新增` 处增加创新。

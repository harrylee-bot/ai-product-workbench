# 案例库

案例库用于给 Decision System 提供历史参照。系统生成策略时，不应该只靠抽象规则，还要引用相似案例、失败教训和可复用流程。

## 核心条目

- [[03-案例库/需求案例库/AI营销助手案例|AI营销助手案例]]
- [[03-案例库/需求案例库/云溪营销活动案例索引|云溪营销活动案例索引]]
- [[03-案例库/前端改版案例|前端改版案例]]

## 使用方式

- 新需求先从 [[01-产品知识/需求输入分类法|需求输入分类法]] 识别业务域。
- 再从对应案例中找相似流程、可复用字段、风险点和验收方式。
- 最后把案例经验传给 [[05-Agent知识/三系统Agent协作规范|三系统 Agent 协作规范]] 中的相关 Agent。

# 案例库

案例库用于给新需求提供历史参照。每个案例应记录业务背景、关键流程、可复用字段、风险点和验收方式。

## 核心条目

- [[03-案例库/需求案例库/AI营销助手案例|AI 营销助手案例]]
- [[03-案例库/需求案例库/云溪营销活动案例索引|云溪营销活动案例索引]]

## 使用方式

- 先从 [[01-产品知识/需求输入分类法|需求输入分类法]] 识别业务域。
- 再从对应案例中找相似流程、可复用字段、风险点和验收方式。
- 涉及奖品、券、抽奖、报表或第三方跳转时，同步读取 [[02-规则约束/需求文档沉淀/营销活动与资损约束|营销活动与资损约束]]。

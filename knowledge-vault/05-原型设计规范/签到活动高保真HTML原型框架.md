# 签到活动高保真HTML原型框架

## 后台页面

### 活动基础

活动名称、活动标题、活动时间、活动集、适用省市、登录方式、用户范围、是否测试活动。

### 页面素材

背景海报、打卡按钮、打卡记录按钮、九宫格背景、抽奖按钮、奖品背景、轮播区域和默认素材。

### 门店与渠道

门店数量、门店名称、门店渠道编码、活动码、运营位和发展人编码。

### 规则与奖励

参与次数、打卡条件、抽奖次数、任务完成条件、积分值、奖品、库存和发放状态。

### 预览与治理

预览、白名单、提交审核、审核结果、发布、下架和数据报表。

## 前台页面

1. 活动首屏和规则入口；
2. 可打卡状态与主按钮；
3. 今日完成、历史记录和门店信息；
4. 获得抽奖次数或积分的反馈；
5. 抽奖/领奖页面；
6. 未登录、无资格、次数用尽、活动未开始、活动已结束和失败态。

## HTML要求

- 单文件可独立打开；
- 内联 CSS 和少量原生 JS；
- 不访问真实接口；
- 不使用真实账号、密钥或生产地址；
- 所有按钮都能演示状态变化；
- 页面结构与 [[02-业务域知识/签到与任务积分活动|签到与任务积分活动]] 一致。

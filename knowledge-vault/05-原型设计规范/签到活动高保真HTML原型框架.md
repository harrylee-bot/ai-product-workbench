# 签到活动高保真HTML原型框架

本页从 `贵州签到打卡.html` 这类 Axure HTML 原型中提炼可复用框架。生成签到、打卡、领积分、连续签到、任务积分活动原型时，必须优先复用本页的信息架构、字段密度、状态表达和前后台联动方式；不要只画一个移动端按钮页。

## 适用场景

- 签到领积分活动。
- 打卡赢奖品/经验值活动。
- 连续签到、累计签到、任务积分、满值兑奖类活动。
- 需要后台配置、前台预览、审核发布、权益/积分发放、数据报表闭环的活动。

## 页面框架

### 后台配置区

后台配置页必须体现运营真实配置密度，至少包括以下分组：

| 分组 | 必须字段/控件 | 页面表现 |
| --- | --- | --- |
| 活动基础设置 | 是否测试活动、活动名称、活动时间、开始时间、结束时间、活动集、适用区域、用户范围、登录方式 | 表单分组展示，必填字段标记，保存/预览/提交审核操作固定可见 |
| 展示配置 | banner 图、背景颜色、海报开关、分享海报图片、页面配置、活动规则标题、背景图、规则背景图、规则背景色 | 采用上传占位、色值/开关、预览联动表达 |
| 任务板块 | 任务一/任务二、标题图、背景图、上标题、下标题、启用状态、打卡按钮、跳转背景图、跳转链接 | 每个任务独立卡片，可增删，可配置跳转类型 |
| 跳转配置 | 189.cn 链接、券多多小程序、奖品、第三方链接、电信 App 原生、无链接 | 用下拉/单选表达，不写真实 URL |
| 话术与异常 | 打卡成功、打卡达到上限、不需要登录、重复中奖、不在活动参与范围、奖品失效、重复领取、无法办理、未满足前置条件 | 异常文案必须在原型中可见 |
| 隐私协议 | 用户隐私协议标题、用户隐私协议内容、增加协议 | 如不涉及真实隐私内容，用占位文案表达 |
| 奖品/积分设置 | 奖品名称、奖品类型、展示名称、库存限制、每日库存、单次打卡经验值、打卡次数上限、目标用户、目标用户来源 | 表格 + 表单组合，显示库存、上限、资损提醒 |
| 活动规则 | 活动规则、增加规则、满值兑奖、奖品领取条件、月度计数清零规则 | 规则列表或可编辑表格表达 |

### 前台预览区

前台预览不能只是静态手机壳，必须展示用户能理解的状态：

| 状态 | 必须展示 |
| --- | --- |
| 首次进入 | banner、活动标题、规则入口、任务卡片、今日可得积分/经验值、打卡按钮 |
| 可打卡 | 主按钮高亮，展示当前打卡次数、连续/累计进度、可获得积分 |
| 打卡成功 | 成功提示、积分/经验值到账提示、下一档奖励或今日已完成 |
| 已打卡/达到上限 | 按钮置灰，展示“今日已打卡”或“已达上限” |
| 无资格/未登录 | 展示登录方式或不可参与原因 |
| 发放失败/稍后到账 | 展示稍后到账、补偿中或查看记录入口 |

### 报表与治理区

高保真原型必须包含报表或治理区，而不是只画前台：

- 筛选：活动时间、渠道、区域、用户范围、状态。
- 指标：访问人数、打卡人数、打卡次数、积分/经验值发放成功、发放失败、补偿中、库存消耗、资损风险。
- 明细：用户标识脱敏、打卡日期、打卡次数、奖励类型、发放状态、失败原因、补偿状态。
- 操作：导出、查看失败、补偿重试、下线活动。

## 高保真 HTML 要求

- 必须输出完整 `<!doctype html>` 单文件，包含内联 CSS。
- 必须有后台导航、顶部操作栏、表单分组、表格、状态标签、前台手机预览、报表/明细区。
- 必须体现上传位、开关、单选/下拉、数值步进或数字输入、主次按钮、异常提示。
- 必须有稳定布局和视觉层级：侧边栏/顶部栏/主内容/预览区或多列工作台。
- 必须使用平台业务风格：运营配置后台偏高密度、克制、可扫描；前台预览可以更活动化，但不能脱离后台配置。
- 禁止使用浏览器默认样式裸排版；禁止只输出 `<h1>`、`<input>`、`<button>` 的简单堆叠。

## 生成时必须继承的产品逻辑

```text
运营配置活动基础信息
  ↓
配置展示素材、任务、签到/打卡规则、奖品/积分权益
  ↓
配置异常文案、隐私协议和目标用户
  ↓
生成前台预览
  ↓
提交审核
  ↓
发布上线
  ↓
用户进入活动页并打卡/签到
  ↓
系统校验用户范围、登录方式、打卡次数、库存/额度
  ↓
发放积分/经验值/奖品或进入失败补偿
  ↓
报表复盘和异常处理
```

## 禁止事项

- 禁止把“知识库命中、模型补齐、联网资料、公开证据、工具日志、运行说明”写进原型画面。
- 禁止生成与本页字段和页面结构无关的通用 SaaS 页面。
- 禁止只展示前台手机页，不展示后台配置、审核发布和报表。
- 禁止写真实接口地址、真实账号、真实密钥或生产链接。

# 历史业务增量原型规则

## 基本原则

- 保留原信息架构和导航。
- 保留原主流程和状态。
- 新增内容放到对应字段组或页面区块。
- 前台影响必须在预览或前台页体现。
- 报表影响必须在筛选、明细、导出或指标里体现。

## 常见增量表达

| 增量 | 原型表达 |
| --- | --- |
| 新字段 | 在原表单字段组中新增，展示默认值、校验、提示。 |
| 新开关 | 展示开关关闭/开启对预览或流程的影响。 |
| 新筛选 | 筛选区新增，列表和导出同步响应。 |
| 新状态 | 状态标签、可执行动作、异常提示。 |
| 新报表列 | 明细表新增列，导出弹窗同步说明。 |
| 新审核规则 | 审核详情展示变更前后值和驳回原因。 |

## 必画对比

- 修改前：原有页面区域或流程。
- 修改后：新增字段/状态/按钮/规则的位置。
- 异常态：新增能力失败、无权限、历史数据为空。
- 历史影响：已发布、待审核、草稿、历史报表如何展示。

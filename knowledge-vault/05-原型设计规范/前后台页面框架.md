# 前后台页面框架

本页是生成原型时的主规范，优先级高于旧版 RP 资产索引。旧版资料中的“前台页面设计框架”“后台管理设计框架”“前后端设计框架”“RP资产到设计框架映射”都要先汇总到这里，再用于正式 PrototypeSpec 或 HTML 原型。

## 后台通用框架

```text
列表/工作台
  → 新建/编辑配置
  → 预览
  → 提交审核
  → 审核详情
  → 发布/下线/回滚
  → 数据报表
```

## 前台通用框架

```text
活动入口
  → 首屏信息
  → 活动规则
  → 参与/领取/预约/下单
  → 结果反馈
  → 分享/二维码/复盘入口
```

## 按业务域选框架

| 业务域 | 后台页面 | 前台页面 |
| --- | --- | --- |
| 活动发布 | 活动列表、模板选择、配置表单、预览审核、报表。 | 活动页、规则、按钮、结果页。 |
| 素材库 | 素材列表、详情、专题标签、审核、引用影响。 | 素材预览、手机端编辑、分享。 |
| 奖品券 | 奖品配置、库存、概率、核销、对账。 | 抽奖、领取、核销结果、失败提示。 |
| OAO | 门店/套餐配置、商机报表、渠道配置。 | 预约表单、门店选择、提交结果。 |
| 报表 | 筛选、指标卡、图表、明细、导出。 | 通常无前台，必要时展示活动数据摘要。 |
| AI助手 | 案例选择、生成工作台、结果预览、确认发布。 | 生成结果预览或活动前台预览。 |

# 前后台页面框架

## 后台活动工作台

1. 顶部：产品入口、组织区域、当前用户和操作状态。
2. 列表：活动名称、类型、区域、时间、状态、创建人、更新时间和操作。
3. 配置向导：选择模板 -> 页面/信息 -> 规则/权益/渠道 -> 预览 -> 提交审核。
4. 详情页：活动配置、审核材料、预览入口、版本和状态变更。
5. 维护操作：编辑、复制、发布、下架、预约下架、重新上架。

## 前台活动页面

- 首屏主视觉、活动标题和利益点；
- 登录/资格/目标用户提示；
- 主操作按钮：参与、打卡、抽奖、领取、预约或加粉；
- 规则、奖品/权益、门店/套餐和活动时间；
- 结果反馈、处理中、失败和补偿状态；
- 分享、二维码、短链或悬浮跳转入口。

## 素材库页面

- 搜索、专题、标签和素材类型筛选；
- 缩略图、审核状态、水印状态和使用状态；
- 创建、编辑、AI 搜索、AI 处理、提交审核和下载；
- “我的申请”和“我的审核”两个视角。

## 数据页面

- 活动、时间、区域、渠道、运营位、发展人和状态筛选；
- 汇总指标与明细列表；
- 脱敏字段、更新时间、口径说明和导出。

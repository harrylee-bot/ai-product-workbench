# 原型设计规范

本目录回答“原型怎么生成”。原型不是画漂亮页面，而是把业务对象、字段、状态、权限、异常和数据口径可视化。

## 生成原则

- 历史业务在原有页面和流程上增量，不重构主路径。
- 新产品必须先落到产品架构中的能力层。
- 后台配置变化必须能在预览或前台页面看到。
- 原型必须覆盖正常态、空态、加载态、失败态、无权限、审核驳回、发布失败。
- HTML 原型不能访问真实接口，不能包含真实密钥、账号和内部地址。

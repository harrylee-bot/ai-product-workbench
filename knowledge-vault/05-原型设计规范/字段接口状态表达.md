# 字段接口状态表达

本页是原型生成时表达字段、接口、状态、错误码和数据口径的主规范，优先级高于旧版“前后端字段与接口口径”来源资产。旧版 RP 文件可以作为来源依据，但正式生成 PrototypeSpec、HTML 原型或 OpenPencil 原型时，应以本页为统一口径。

## 字段表达

每个字段在原型中要能看出：

- 字段名称和所属对象。
- 必填或选填。
- 默认值。
- 校验错误。
- 是否影响预览。
- 是否影响报表。
- 是否需要权限或审核。

## 接口表达

原型不写真实接口地址，但要表达数据契约：

| 契约 | 原型表达 |
| --- | --- |
| 请求参数 | 表单字段、筛选条件、隐藏参数说明。 |
| 响应数据 | 列表、卡片、图表、状态标签。 |
| 错误码 | 失败提示、重试、回退方案。 |
| 权限失败 | 无权限页面或禁用态。 |
| 数据延迟 | 更新时间、数据同步中提示。 |

## 状态表达

- loading：加载中、生成中、导出中、提交中。
- empty：无素材、无活动、无数据、无权限范围。
- error：接口失败、生成失败、发布失败、导出失败。
- disabled：无权限、状态不允许、审核中不可编辑。
- success：提交成功、发布成功、生成成功、导出成功。
- warning：高风险操作、库存不足、历史影响、数据延迟。

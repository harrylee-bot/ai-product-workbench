# 字段接口状态表达

## 字段

每个字段至少说明名称、类型、是否必填、默认值、枚举、校验、权限、数据来源和保存时机。

活动字段示例：活动名称、活动标题、活动类型、活动集、时间、适用省市、用户范围、登录方式、参与次数、渠道编码和发展人编码。

## 接口

原型只描述接口意图，不写真实地址。至少表达请求触发、参数来源、加载状态、成功结果、失败原因、重试和幂等行为。

## 状态

状态必须能回答“谁在什么条件下可以执行什么操作”：

| 状态 | 可见动作 |
| --- | --- |
| 草稿 | 编辑、预览、提交审核 |
| 待审批/审核中 | 查看、撤回或等待审核 |
| 审核通过 | 发布 |
| 已上架 | 预览、下架、复制、详情 |
| 已下架 | 重新上架、详情 |
| 发放中/补偿中 | 查看进度、重试或转人工 |

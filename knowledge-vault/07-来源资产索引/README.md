## 使用方式

1. 先按业务域或案例索引找到主题。
2. 打开逐项阅读索引，按文件名和页码/章节定位依据。
3. 对 PPT/PPTX/DOC 查阅文字步骤和配置说明。
4. 对 RP/HTML 查阅页面结构、字段组织和交互表现。
5. 需要发布或迁移时只引用明确的原始文件路径。

## 使用规则

- 需要找原始需求来源、文件名、导入记录时读取这里。
- 需要写 PRD 时，先读取 [[04-产品文档规范/README|产品文档规范]]，再从这里核验来源。
- 需要生成原型时，先读取 [[05-原型设计规范/README|原型设计规范]]，再从这里找原型资产。
- 旧版整理保留历史路径和内容，但主知识以后维护在新目录中。

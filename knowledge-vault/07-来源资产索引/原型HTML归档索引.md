## 使用边界

- HTML 归档只用于页面结构、文案、字段分组、状态和交互表现的回查。
- HTML 页面中出现的真实地址、账号、演示数据和外部链接不写入知识正文。
- 页面中只有视觉表现、没有手册文字确认的内容，标记为原型表现，不推导后端接口、权限合同或生产状态机。
- 需要复用时，先查本索引定位页面，再回到对应业务条目和原始手册页码。

## 使用方式

1. 先按项目目录定位主题。
2. 再按页面名定位 `index.html`、页面 HTML 和 `files/*/data.js`。
3. 业务规则回查 [[07-来源资产索引/原始文件逐项阅读索引|原始文件逐项阅读索引]] 中的 PPT/DOC 页码。
4. RP、HTML 和手册出现差异时，按 [[00-知识库使用规范/知识分层与冲突裁决|知识分层与冲突裁决]] 处理。

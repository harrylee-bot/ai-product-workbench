## 使用方式

- 先从 [[07-来源资产索引/旧版整理/00-AI使用总纲/业务域到产品逻辑映射|业务域到产品逻辑映射]] 识别业务域对应的产品逻辑。
- 再从对应案例中找相似流程、可复用字段、风险点和验收方式。
- 如果用户要“新增/优化历史业务”，同步读取 [[07-来源资产索引/旧版整理/00-AI使用总纲/产品进化方向判断规则|产品进化方向判断规则]]，判断应继承哪些历史结构。
- 涉及奖品、券、抽奖、报表或第三方跳转时，同步读取 [[07-来源资产索引/旧版整理/02-规则约束/需求文档沉淀/营销活动与资损约束|营销活动与资损约束]]。
- 涉及素材库、专题、标签、后台审核、一人一码和运营日志时，优先读取 [[07-来源资产索引/旧版整理/03-案例库/需求案例库/素材库与活动治理案例补充|素材库与活动治理案例补充]]。

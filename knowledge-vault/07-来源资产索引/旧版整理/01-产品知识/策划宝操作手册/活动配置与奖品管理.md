# 活动配置与奖品管理

本页沉淀新建活动、分步式/整合式配置、活动类型配置、奖品管理和销售品管理相关操作规则。

## 新建活动流程

| 阶段 | 操作要点 |
| --- | --- |
| 选择模板 | 按活动类型、节日类型筛选模板，选择目标模板进入配置。 |
| 活动信息配置 | 填写活动名称、活动时间、适用范围、活动规则、隐私协议等基础信息。 |
| 活动规则配置 | 配置参与条件、登录方式、奖品、参与次数、中奖次数、目标用户等规则。 |
| 海报配置 | 上传或替换活动海报，修改图片、文案、标题和福利信息。 |
| 完成创建 | 可保存草稿或提交审核；提交前系统校验完整性。 |

## 配置方式对比

| 对比维度 | 分步式配置 | 整合式配置 |
| --- | --- | --- |
| 流程结构 | 拆成选择模板、活动信息配置、活动规则配置、海报配置 4 个独立步骤。 | 基础设置、奖品、页面等配置项集中在一个页面。 |
| 操作体验 | 步骤清晰，适合新手或复杂活动，不容易遗漏。 | 可随时调整任意配置项，适合熟悉系统的用户快速迭代。 |
| 信息可见性 | 当前步骤只显示对应配置项，信息聚焦但不便全局预览。 | 所有配置项在同一页面，可实时关联调整和预览。 |
| 灵活性 | 修改前序步骤时需要返回，流程固定。 | 支持边配置边预览，灵活性更高。 |

## 活动类型配置

| 活动类型 | 基础配置 | 核心配置 |
| --- | --- | --- |
| 抽奖类活动 | 选择抽奖模板，填写活动名称、时间、适用范围等。 | 配置奖品名称、数量、中奖概率、奖品图片、参与次数、中奖次数、目标用户和抽奖界面。 |
| 资费订购类活动 | 选择资费订购模板，填写基础信息并上传页面图片。 | 选择资费产品，配置赠送权益和发放规则，明确参与条件和限制。 |
| 商机预约类活动 | 选择商机预约模板，填写基础信息。 | 设置参与次数上限，关联 OAO 商机单奖品，配置预约门店信息。 |
| 聚合页面类活动 | 选择聚合页面模板，填写基础信息。 | 配置客户经理/企微员工列表，并与活动绑定。 |
| 答题类活动 | 选择答题/问卷模板，填写基础信息。 | 添加问题，配置题型、必填、公共问题、正确答案展示等。 |
| 问卷抽奖类活动 | 选择问卷抽奖模板，填写基础信息。 | 配置问题、抽奖联动、参与次数、中奖次数、目标用户和二次确认。 |
| AI 能力类活动 | 选择 AI 能力模板，填写基础信息。 | 配置广告位、跳转链接、抽奖奖品、门店打卡等能力。 |

## 奖品管理

### 独立奖品

- 入口：左侧导航栏「奖品管理」下的「独立奖品」。
- 搜索维度：奖品编号、奖品名称、奖品类型、我的奖品。
- 奖品类型示例：实物奖品、流量包、优惠券、自有产品等。
- 我的奖品：仅展示当前账号创建的奖品。
- 重置：清空搜索条件并恢复默认列表。

### 销售品管理

- 用于管理与活动订购、权益发放、订单统计相关的销售品。
- 创建奖品/产销品时要选择普通订单或高值订单分类。
- 订单分类可二次编辑，但历史统计订单数据不会回写变更。

## 奖品与抽奖风险规则

- 抽奖类活动要明确中奖概率、库存、参与次数、中奖次数和目标用户规则。
- 轮询发放开启时，只能抽中已配置概率且有库存的奖品；关闭时保持原抽奖逻辑。
- 九宫格、大转盘、盲盒、砸金蛋、扭蛋等抽奖组件必须确保奖品概率和口径可解释。
- AI 能力类活动中如配置抽奖楼层，所有奖品中奖概率之和应满足活动规则，且要有兜底奖项。
- 涉及奖品、优惠券、库存和发放失败时，应记录对账、回退和异常提示。

# 素材库操作手册

AI 策划宝素材库面向集团及各省业务，提供营销素材管理、AI 编辑、快速审核、快速发布，并与活动发布平台联动，支持一线人员快速创建加粉海报和企微一人一码海报。

## PC 端首页

- 首页用于快速查找营销素材、查看营销日历、筛选素材。
- 顶部搜索框支持输入创意关键词，例如节日、活动主题、终端合约等。
- 灵感搜索用于匹配对应主题素材。
- 营销日历展示近期关键营销节点和距离天数，便于提前规划素材。
- 精选素材区展示节气海报、活动 Banner、调查问卷物料等现成素材。

## 策划宝个人区

| 模块 | 用途 |
| --- | --- |
| 我的素材 | 查看自己创建、编辑或使用的素材。 |
| 我的申请 | 查看自己提交的素材申请和处理状态。 |
| 我的审核 | 查看待自己处理或已处理的审核任务。 |
| 最近设计 | 查看近期编辑过的素材或海报。 |
| 海报管理 | 管理已生成或已发布的海报。 |

## 素材管理

| 模块 | 操作场景 | 关键规则 |
| --- | --- | --- |
| 素材审核 | 查看已提交素材，或修改已通过审核素材的名称、标签等。 | 修改后需要保留审核状态和操作记录。 |
| 标签管理 | 管理素材标签体系。 | 标签影响素材筛选、搜索和推荐，应保持命名统一。 |
| 审核管理 | 管理素材审核流程。 | 需要明确审核人、审核状态、通过/驳回原因。 |
| 导入管理 | 批量导入素材。 | 需要记录导入批次、失败原因和重复处理规则。 |
| 审核员管理 | 配置素材审核员。 | 审核员权限应按组织、角色和业务范围控制。 |
| 审核规则 | 配置审核策略。 | 应明确哪些素材进入人工审核、哪些规则自动处理。 |

## 营销管理

| 模块 | 操作场景 | 关键规则 |
| --- | --- | --- |
| 专题管理 | 查询、新增、编辑专题，配置专题素材，启用/禁用专题，复制专题。 | 专题 ID、创建时间、状态是主要筛选条件。 |
| 分类管理 | 管理素材分类。 | 分类影响素材归档、搜索和前台展示。 |
| 日历管理 | 管理营销节点和日历内容。 | 日历用于运营提前规划素材。 |
| 标签管理 | 管理营销标签。 | 标签应与素材标签体系保持一致。 |
| 角标管理 | 管理素材角标展示。 | 需明确角标展示优先级和适用范围。 |
| 广告位管理 | 管理首页或专题广告位。 | 需明确上架时间、下架时间、跳转链接和投放范围。 |

## 用户信息查询

- 用于按权限查询素材库用户信息。
- 涉及用户信息时，应遵守最小可见、脱敏展示和查询留痕。
- 若支持导出，应绑定导出权限和导出日志。

## 手机端

| 模块 | 操作场景 |
| --- | --- |
| 首页 | 浏览营销活动 Banner、节日专题、素材分类；支持搜索素材并进入编辑页面。 |
| 模板 | 浏览和选择模板，进入素材制作或海报编辑。 |
| 我的 | 管理个人素材、申请、审核、最近设计、海报管理和 AI 搜索。 |
| 最近设计 | 查看近期设计内容，便于继续编辑。 |
| 我的素材 | 管理个人创建或保存的素材。 |
| 我的申请 | 查看提交申请及状态。 |
| 我的审核 | 处理或查看审核任务。 |
| 海报管理 | 管理生成后的海报。 |
| AI 搜索 | 通过意图或关键词搜索素材。 |

## 与活动发布平台联动

- 素材库素材可用于活动创建和海报配置。
- 素材替换、下线、同步时必须明确对草稿、待审核、已发布活动的影响。
- 企微一人一码海报需要明确码的生成、绑定、下载、复制、失效和数据统计规则。
- 素材标签传输能力会影响活动侧筛选、推荐和统计，需保持字段一致。

# 数据报表与数字大屏

本页沉淀活动报表、运营位与渠道编码、数字大屏和平台运营数据统计的操作知识。

## 活动报表范围

活动报表覆盖活动订单、抽奖活动、商机预约、活动客流、活动清单、打卡活动、厅店打卡数据、问卷分析、问卷抽奖、问卷活动、活动统计、互联网卡报表、派出所报表、加粉数据、一人一码订单等。

## 运营位与渠道编码透传

- 适用场景：聚合页（新）链接单点跳转模板，适合一个活动配置多条省内跳转链接。
- 常见参数：
  - `actNo`：活动编码。
  - `utm_ch`：渠道编码。
  - `utm_sch`：运营位编码。
- 使用要求：
  - 不同投放渠道应使用不同渠道编码或运营位编码。
  - 跳转链接应携带活动编码、渠道编码、运营位编码等参数。
  - 后续报表应支持按渠道、运营位做统计和闭环分析。

## 活动报表近期优化口径

- 活动订单报表新增活动类型筛选字段。
- 活动客流报表补充转化类指标，关注订单提交量、发券成功量等效果数据。
- 问卷活动详情报表支持按当前查询条件导出明细。
- 商机预约报表新增省份查询条件，支持多选省份与活动名称、活动编码、时间等组合查询。
- 导出文件应按当前筛选条件生成，便于省侧复盘。

## 数字大屏

### 平台使用情况

| 模块 | 说明 |
| --- | --- |
| 关键指标展示 | 展示总用户数、月用户数、当月发布活动等核心运营指标及环比变化。 |
| 功能使用量查询 | 支持最近 7 日、最近 30 日维度切换，查看功能使用排行。 |
| 区域使用分布 | 通过全国地图展示省份/集团使用情况，支持下钻查看省份明细。 |
| 省使用情况 TOP5 | 对比累计发布活动数和总用户数排名前 5 的省份。 |

### 云溪活动视图

| 模块 | 说明 |
| --- | --- |
| 日期范围筛选 | 设置起止日期后，页面模块联动更新。 |
| 区域分布 | 以全国地图展示各省订单量层级。 |
| 专区转化漏斗 | 按专区展示 PV、UV、订单量和累计转化率。 |
| 指标总览 | 展示模板数、已开展活动数、进行中活动数、PV、UV、订单量和转化率。 |
| 趋势分析 | 展示发布、客流、订单等趋势。 |

## 平台运营数据统计

| 报表 | 主要筛选 | 重点字段 |
| --- | --- | --- |
| 平台账号统计 | 日期、组织方、账号类型。 | 总用户数、去重用户数、组织方。 |
| 活动量统计 | 日期、组织方、活动集、是否测试活动。 | 活动所属组织、活动数量、测试/正式活动。 |
| 订单量统计 | 查询时间、组织方、活动名称/编码、活动状态、创建时间、活动类型、活动集。 | 订单量、活动状态、活动类型、创建时间。 |
| 奖品列表 | 奖品编号、奖品名称、奖品类型、我的奖品、活动集。 | 奖品库存、奖品类型、创建人、关联活动集。 |

## 报表导出规则

- 导出应与当前筛选条件一致。
- 报表字段需要明确统计口径和时间口径。
- 涉及用户明细、订单、号码、个人信息时，应脱敏并记录导出日志。
- 省份、组织方、活动集等权限边界必须与账号角色匹配。
- 测试活动是否计入统计需要在报表口径中明确。

## 可复用页面模式

| 页面模式 | 常见来源 | 复用规则 |
| --- | --- | --- |
| 活动列表/活动卡片 | 多省活动、订购类、OAO、抽奖原型 | 状态、筛选、分页、操作按钮必须与活动生命周期一致。 |
| 活动配置页 | 聚合页、互联网卡、商机预约、抽奖、低升高 | 左侧预览 + 右侧配置或分步配置都要支持草稿、校验、提交审核。 |
| 奖品配置页 | 奖品运营、抽奖重构、广西抽奖 | 奖品类型、库存、概率、发放规则和异常回退必须显式配置。 |
| 素材选择/同步页 | 素材选择、素材同步云溪、素材重构 | 素材来源、标签、搜索、预览、引用影响范围必须明确。 |
| 报表页 | 一人一码数据报表、首页数据 | 筛选、字段口径、权限、导出、更新时间必须明确。 |
| 省份专项活动页 | 四川、广西、江西、湖南、贵州、北京/安徽/河北 | 省份权限、活动模板差异、地方渠道参数和复盘指标必须明确。 |

## HTML 原型导出包

- `原型转HTML.zip`：HTML 原型导出包，已归档到项目 `storage/source-assets/prototype-html/原型转HTML.zip`，用于查看可浏览页面、样式、交互数据和图片素材。
- `html.zip`：33 套 HTML 原型和演示页面的补充导出包，已归档到 `storage/source-assets/prototype-html/html.zip`；其中 29 套可按项目名或明显同义命名映射到上方 `.rp` 资产，另有 `手签`、`营销助手`、`营销日历`、`衡阳` 四套补充来源。
- 结构化索引：[[07-来源资产索引/旧版整理/01-产品知识/手册与原型资料库/原型转HTML资产索引-2026-07-03|原型转HTML资产索引-2026-07-03]]、[[07-来源资产索引/旧版整理/01-产品知识/手册与原型资料库/HTML原型补充资产索引-2026-07-10|HTML原型补充资产索引-2026-07-10]]。
- 使用方式：先用本索引定位来源，再解包查看具体 HTML 页面；不要把压缩包内乱码文件名直接作为业务页面名称。

## 原型使用注意

- `.rp` 是原型源文件，不直接作为线上知识页展示。
- 需要生成新原型时，先读取对应业务域和页面模式，再参考原型文件名定位原始源文件。
- 对于旧原型或命名不清的文件，应先确认业务场景，再沉淀为结构化知识。

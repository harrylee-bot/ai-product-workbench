# 运营配置与素材库治理约束

本页沉淀自 [[07-来源资产索引/旧版整理/01-产品知识/需求文档知识库/需求资产清单-2026-06-23|需求资产清单-2026-06-23]]，用于处理素材库、专题、模板、活动码、一人一码、运营日志、报表导出和审核发布类需求。

## 必须遵守

| 编号 | 规则 | 适用场景 |
| --- | --- | --- |
| OPS-MAT-001 | 配置类需求必须同时写清后台配置项、前台展示效果、默认值、异常提示和上线后可回滚方式。 | 素材库、专题、模板、活动配置 |
| OPS-MAT-002 | 审核发布链路必须包含提交、审核、驳回、发布、下线、修改后再审核和操作日志。 | 素材发布、模板发布、后台操作审核 |
| OPS-MAT-003 | 素材替换、素材同步、素材下线必须说明影响范围，区分历史活动、已发布活动、待发布活动和新建活动。 | 固定素材替换、老素材库同步、新素材库接入 |
| OPS-MAT-004 | 用户查询、登录维度、报表导出、白名单和权限开放必须补充个人信息、角色边界、省份边界和脱敏策略。 | 用户明细、登录数、报表、白名单 |
| OPS-MAT-005 | 活动码、一人一码、短链和企微链路必须明确生成规则、绑定关系、跳转目标、失效机制和重复生成处理。 | 活动码、一人一码、短链加粉 |
| OPS-MAT-006 | 专题、标签、筛选、排序、搜索类需求必须说明默认排序、空状态、无权限状态、搜索无结果和历史数据兼容。 | 专题管理、标签体系、关联搜索 |
| OPS-MAT-007 | 运营日志必须记录操作人、操作对象、操作时间、变更前后值、结果状态和失败原因。 | 后台操作、审核发布、数据修改 |
| OPS-MAT-008 | 报表导出必须明确字段口径、导出权限、导出格式、数据时效、脱敏要求和操作留痕。 | 用户明细、省份报表、运营数据看板 |

## 优先偏好

- 优先复用既有素材库、模板、专题和审核组件，减少跨端差异。
- 优先把“配置、预览、审核、发布、统计、日志”作为同一闭环设计，而不是分散成孤立页面。
- 优先以角色和省份控制数据范围，避免只靠前端隐藏入口。
- 优先对新增字段给出历史数据补全规则和空值显示规则。

## 避免事项

- 避免只描述“新增按钮”或“新增字段”，不描述状态流转和权限边界。
- 避免把报表口径写成页面展示文案，必须补充计算口径和导出口径。
- 避免上线后直接影响已发布活动，素材替换和模板替换需要灰度或回滚方案。
- 避免跳过评审记录表中的风险项，尤其是个人信息、白名单、权限、日志和对账。

## 验收清单

- 是否写清配置入口、配置字段、默认值、展示位置和前后台联动。
- 是否覆盖审核、发布、下线、修改、驳回和异常提示。
- 是否明确权限、角色、省份、白名单和个人信息处理方式。
- 是否补充运营日志、数据统计、报表导出和对账规则。
- 是否说明历史数据兼容、异常兜底和回滚方式。

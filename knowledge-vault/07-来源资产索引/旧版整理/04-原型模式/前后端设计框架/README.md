# 前后端设计框架知识库

本目录把 `手册+原型.zip` 中的 Axure `.rp` 原型资产沉淀为可复用的前台页面、后台管理、字段接口和原型生成规则。它不是源文件清单，而是给 Prototype Designer Agent 和 Prototype Code Agent 使用的设计框架知识。

## 使用目标

- 生成原型时，先判断需求属于前台活动页、后台配置页、数据报表页、素材库页、奖品券页还是号卡/OAO 页。
- 按页面类型选择对应框架，再补齐状态、字段、校验、权限、异常态和数据口径。
- HTML 原型只演示业务结构和交互状态，不访问真实接口，不暴露真实接口地址。
- OpenPencil/HTML 原型必须保留页面、组件、字段、状态与 ProductDesignState 的映射。

## 生成原型的默认链路

```text
识别业务域
  ↓
选择前台/后台/报表/素材/奖品/OAO 页面框架
  ↓
补齐页面结构、组件、字段和状态
  ↓
补齐前后端交互口径、校验和异常兜底
  ↓
生成 PrototypeSpec
  ↓
生成单文件 HTML + OpenPencil 文档
```

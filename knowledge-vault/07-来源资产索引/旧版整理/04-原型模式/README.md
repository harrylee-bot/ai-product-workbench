## 关键原则

- 生成原型前先读取 [[07-来源资产索引/旧版整理/00-AI使用总纲/原型生成与历史复用策略|原型生成与历史复用策略]]，判断历史业务增量还是新产品创新。
- 新产品原型必须落回 [[07-来源资产索引/旧版整理/00-AI使用总纲/产品架构与能力地图|产品架构与能力地图]]，说明与活动、素材、奖品、报表、权限、审核、AI 助手的关系。
- 需求涉及活动、素材、奖品、报表或号卡模板时，应同时考虑用户端页面和后台配置端。
- 后台配置需要覆盖字段、默认值、校验、权限、状态流转和审计记录。
- 预览、二维码、审核、发布、下线、回滚和数据统计应作为完整闭环设计。
- 奖品/券/跳转/报表类需求必须展示异常态、空态和失败兜底。
- 素材库、专题、标签、活动码、一人一码和运营日志类需求必须同步读取 [[07-来源资产索引/旧版整理/02-规则约束/需求文档沉淀/运营配置与素材库治理约束|运营配置与素材库治理约束]]。
- 活动模板、配置手册和 Axure 原型类需求必须同步读取 [[07-来源资产索引/旧版整理/04-原型模式/需求文档沉淀/活动模板配置与原型模式|活动模板配置与原型模式]]。
- 生成 HTML/OpenPencil 原型时，必须优先读取 [[07-来源资产索引/旧版整理/04-原型模式/前后端设计框架/README|前后端设计框架知识库]]，区分前台页面、后台管理、字段接口和 RP 资产映射。

### 后台配置区

后台配置页必须体现运营真实配置密度。所有签到/打卡活动先实现以下核心分组：

| 分组 | 必须字段/控件 | 页面表现 |
| --- | --- | --- |
| 活动基础设置 | 是否测试活动、活动名称、活动时间、开始时间、结束时间、活动集、适用区域、用户范围、登录方式 | 表单分组展示，必填字段标记，保存/预览/提交审核操作固定可见 |
| 展示配置 | banner 图、背景颜色、海报开关、分享海报图片、页面配置、活动规则标题、背景图、规则背景图、规则背景色 | 采用上传占位、色值/开关、预览联动表达 |
| 签到/任务规则 | 签到项、启用状态、签到主按钮、自然日口径、每日次数上限、连续/累计进度、幂等规则 | 表格或独立任务卡表达，规则值、开关、次数和进度可评审 |
| 话术与异常 | 签到成功、今日已签到、未登录、无资格、额度或库存不足、发放失败、补偿中 | 成功、上限、资格和发放异常文案必须在原型中可见 |
| 用户范围 | 用户范围、目标用户来源、登录方式 | 明确参与范围和登录校验，不暴露内部人群规则 |
| 隐私与授权 | 隐私协议标题、隐私协议内容、同意授权控件、协议查看入口 | 没有真实协议时使用业务占位内容，不得省略授权状态 |
| 积分/权益设置 | 权益名称、权益类型、单次发放值、每日额度或库存、总额度或库存、次数上限、资损提醒 | 表格 + 表单组合，区分额度/库存、上限和风险提示 |
| 活动规则 | 自然日口径、参与条件、次数或累计规则、幂等规则、额度或库存规则、清零规则 | 规则列表或可编辑表格表达；不涉及清零时明确显示不清零 |

以下分组只在需求命中对应模式时增加，不得因为来源原型里出现过就强塞进所有签到活动：

| 按需分组 | 按需字段/控件 | 适用条件 |
| --- | --- | --- |
| 连续/累计任务扩展 | 任务一/任务二、标题图、上下标题、周期、连续中断、补签、启用状态 | 需求包含连续签到、累计签到、多任务或补签 |
| 跳转配置 | 站内页面、小程序、第三方链接、App 原生、奖品页、无跳转 | 签到按钮或任务完成后确有跳转；不写真实生产 URL |
| 奖品发放扩展 | 奖品名称、奖品类型、每日库存、总库存、失效时间、重复领取限制 | 奖励是实物、券或奖品，不是纯积分 |
| 满值/周期扩展 | 满值兑奖、奖品领取条件、周期计数、月度清零 | 需求包含满值兑奖、周期任务或月度重置 |

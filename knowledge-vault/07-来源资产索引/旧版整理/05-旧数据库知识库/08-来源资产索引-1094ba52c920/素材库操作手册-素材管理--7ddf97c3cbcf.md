## 素材管理

| 模块 | 操作场景 | 关键规则 |
| --- | --- | --- |
| 素材审核 | 查看已提交素材，或修改已通过审核素材的名称、标签等。 | 修改后需要保留审核状态和操作记录。 |
| 标签管理 | 管理素材标签体系。 | 标签影响素材筛选、搜索和推荐，应保持命名统一。 |
| 审核管理 | 管理素材审核流程。 | 需要明确审核人、审核状态、通过/驳回原因。 |
| 导入管理 | 批量导入素材。 | 需要记录导入批次、失败原因和重复处理规则。 |
| 审核员管理 | 配置素材审核员。 | 审核员权限应按组织、角色和业务范围控制。 |
| 审核规则 | 配置审核策略。 | 应明确哪些素材进入人工审核、哪些规则自动处理。 |

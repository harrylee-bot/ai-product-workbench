## 可复用页面模式

| 页面模式 | 常见来源 | 复用规则 |
| --- | --- | --- |
| 活动列表/活动卡片 | 多省活动、订购类、OAO、抽奖原型 | 状态、筛选、分页、操作按钮必须与活动生命周期一致。 |
| 活动配置页 | 聚合页、互联网卡、商机预约、抽奖、低升高 | 左侧预览 + 右侧配置或分步配置都要支持草稿、校验、提交审核。 |
| 奖品配置页 | 奖品运营、抽奖重构、广西抽奖 | 奖品类型、库存、概率、发放规则和异常回退必须显式配置。 |
| 素材选择/同步页 | 素材选择、素材同步云溪、素材重构 | 素材来源、标签、搜索、预览、引用影响范围必须明确。 |
| 报表页 | 一人一码数据报表、首页数据 | 筛选、字段口径、权限、导出、更新时间必须明确。 |
| 省份专项活动页 | 四川、广西、江西、湖南、贵州、北京/安徽/河北 | 省份权限、活动模板差异、地方渠道参数和复盘指标必须明确。 |

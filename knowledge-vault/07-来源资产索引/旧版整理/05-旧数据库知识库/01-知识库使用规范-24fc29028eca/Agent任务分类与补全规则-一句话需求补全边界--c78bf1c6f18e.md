## 一句话需求补全边界

Agent 可以补全：

- 默认角色和权限范围。
- 常见后台配置页、前台参与页、预览审核页、报表页。
- 字段、状态、校验、空态、失败态、无权限态。
- 常规验收项、数据口径和风险清单。
- 与历史案例相似的流程和页面框架。

Agent 不能臆造：

- 真实活动预算、奖品成本、概率、库存和资损阈值。
- 真实接口地址、密钥、生产账号和内部运维信息。
- 监管、财务或合同类硬性规则。
- 用户明确没有授权的历史数据迁移或线上发布动作。

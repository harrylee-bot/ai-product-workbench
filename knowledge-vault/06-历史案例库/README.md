# 历史案例库

本目录用于给新需求提供历史参照。案例不是主知识入口，而是用于补充业务细节、历史风险和相似实现。

## 核心文件

- [[06-历史案例库/案例复用索引|案例复用索引]]

## 使用规则

- 先读 [[02-业务域知识/README|业务域知识]]，再读案例。
- 历史业务增量必须找相似案例，但不能照搬单省配置。
- 案例用于判断已有路径、风险和验收，不用于替代产品架构。
- 涉及奖品、券、导出、权限、外链时，必须同步读取 [[04-产品文档规范/验收风险清单|验收风险清单]]。

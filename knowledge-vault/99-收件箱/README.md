# 收件箱

收件箱只用于临时存放未经整理的业务资料，不作为 AI 正式生成 PRD 或原型的第一召回入口。

整理时先判断资料能否沉淀为可复用知识：可推理的产品规则、业务逻辑、文档规范和原型模式进入主知识目录；原始文件清单、导入记录和旧版路径保留在 [[07-来源资产索引/README|来源资产索引]]。

## 处理规则

- 只是原始资料：保留来源，等待拆分。
- 能形成产品架构、能力地图、核心对象或端到端流程：迁移到 [[01-产品架构/README|产品架构]]。
- 能形成业务域对象、流程、字段、状态、数据或风险：迁移到 [[02-业务域知识/README|业务域知识]]。
- 能形成历史增量、新能力创新或产品演进判断：迁移到 [[03-产品进化规划/README|产品进化规划]]。
- 能形成 PRD 结构、写作规则、验收标准或风险清单：迁移到 [[04-产品文档规范/README|产品文档规范]]。
- 能形成页面框架、字段接口状态、原型复用或前后台联动模式：迁移到 [[05-原型设计规范/README|原型设计规范]]。
- 能形成可复用历史案例、相似流程或风险经验：迁移到 [[06-历史案例库/README|历史案例库]]。
- 只是导入清单、来源台账、旧版整理或原始资料索引：迁移到 [[07-来源资产索引/README|来源资产索引]]。

## 禁止放入

- 平台自身架构说明。
- 工具自身 UI 改造说明。
- 内部执行流程、平台技术架构、工程实现说明。

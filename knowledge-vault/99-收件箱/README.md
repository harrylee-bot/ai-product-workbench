# 收件箱

收件箱只用于临时存放。所有内容最终都应该归档到 [[01-产品知识/README|产品知识]]、[[02-规则约束/README|规则约束]]、[[03-案例库/README|案例库]]、[[04-原型模式/README|原型模式]] 或 [[05-Agent知识/README|Agent 知识]]。

## 处理规则

- 只是原始资料：保留来源，等待拆分。
- 能形成规则：迁移到 [[02-规则约束/README|规则约束]]。
- 能形成案例：迁移到 [[03-案例库/README|案例库]]。
- 能形成页面或交互模式：迁移到 [[04-原型模式/README|原型模式]]。
- 能形成 Agent 输入输出规则：迁移到 [[05-Agent知识/README|Agent 知识]]。

## 图谱要求

收件箱内容默认不作为核心节点。整理完成后，必须按 [[00-系统说明/知识图谱维护规则|知识图谱维护规则]] 增加双链。

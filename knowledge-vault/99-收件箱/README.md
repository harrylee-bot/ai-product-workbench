# 收件箱

收件箱只用于临时存放业务资料。所有内容最终都应该归档到 [[01-产品知识/README|产品知识]]、[[02-规则约束/README|规则约束]]、[[03-案例库/README|案例库]] 或 [[04-原型模式/README|原型模式]]。

## 处理规则

- 只是原始资料：保留来源，等待拆分。
- 能形成业务域或需求类型：迁移到 [[01-产品知识/README|产品知识]]。
- 能形成规则：迁移到 [[02-规则约束/README|规则约束]]。
- 能形成案例：迁移到 [[03-案例库/README|案例库]]。
- 能形成页面或后台配置模式：迁移到 [[04-原型模式/README|原型模式]]。

## 禁止放入

- 平台自身架构说明。
- 工具自身 UI 改造说明。
- 内部执行流程、平台技术架构、工程实现说明。

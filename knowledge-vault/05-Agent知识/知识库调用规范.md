# 知识库调用规范

知识库调用规范用于保证系统不是“凭空生成”，而是基于可维护、可追溯的知识图谱工作。

## 调用顺序

1. 读取 [[01-产品知识/需求输入分类法|需求输入分类法]]，识别输入类型。
2. 读取 [[02-规则约束/系统级强约束|系统级强约束]]，构建基础约束。
3. 按业务域读取相关知识：
   - AI 营销：[[03-案例库/需求案例库/AI营销助手案例]]
   - 营销活动：[[03-案例库/需求案例库/云溪营销活动案例索引]]
   - 奖品资损：[[02-规则约束/需求文档沉淀/营销活动与资损约束]]
   - 页面配置：[[04-原型模式/需求文档沉淀/配置化页面与后台模式]]
4. 读取 [[04-原型模式/AI结果中心预览模式|AI 结果中心预览模式]]，确定展示方式。
5. 把所有引用写入 knowledgeRefs。

## knowledgeRefs 格式

```json
[
  {
    "title": "系统级强约束",
    "path": "02-规则约束/系统级强约束.md",
    "reason": "本次输入涉及系统流程和 Patch Preview",
    "weight": 1
  }
]
```

## 命中规则

- `must_follow` 权重最高，违反则不能执行。
- `avoid` 用于过滤高风险策略。
- `prefer` 用于策略排序。
- `warn` 用于提示追问、评审或人工确认。

## 记录要求

每次系统运行需要记录：

- 输入文本。
- 命中的知识条目。
- 命中的约束。
- 生成策略。
- 选中策略。
- Agent 输出摘要。
- 最终结果。
- Evolution 反馈。

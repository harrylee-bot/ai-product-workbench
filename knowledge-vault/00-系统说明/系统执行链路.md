# 系统执行链路

系统执行链路定义从用户输入到结果展示的完整路径。前端不展示工具按钮，而是在聊天流里展示“系统执行到了哪里”。

## 标准链路

```text
用户输入
  ↓
意图识别
  ↓
知识检索
  ↓
约束构建
  ↓
多策略生成
  ↓
评审与选择
  ↓
PRD / Prototype / Patch Preview
  ↓
结果展示
  ↓
决策记录和进化
```

## 聊天流展示

执行路径应该像对话消息一样出现，而不是放到独立复杂面板里。默认收起，只露出状态摘要。

示例：

```text
执行路径  已完成
约束、决策、评审、补丁预览与进化记录统一展示
```

展开后显示：

- 约束命中：读取了哪些知识和规则。
- 决策策略：生成了哪些策略、为什么选中当前策略。
- Agent 状态：每个 Agent 的输入、输出摘要和耗时。
- 结果产物：PRD、Prototype、Patch Preview。
- 进化记录：本次策略被提升、降级或保持中性。

## 状态定义

| 状态 | 含义 | UI 表现 |
| --- | --- | --- |
| 排队中 | 已收到输入，等待执行 | 灰色状态点 |
| 执行中 | Agent 或系统正在处理 | 蓝色动态状态 |
| 待确认 | 需要用户确认结果或预览 | 黄色状态 |
| 已完成 | 本轮执行完成 | 绿色状态 |
| 失败 | 需要展示原因和可恢复动作 | 红色状态 |

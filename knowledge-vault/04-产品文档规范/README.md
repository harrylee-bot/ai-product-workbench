# 产品文档规范

PRD 必须把业务目标落到活动、模板、页面、规则、奖品、渠道、商机、权限和数据对象上，不只描述页面文案。

本地候选规范现以本机 Codex 需求文档技能为依据：业务章按实际功能编排，流程图和产品架构图分别按需选择。仅覆盖本次需求涉及的对象，不把业务域检查项扩写为新增范围。技能整理及现有 Canvas 协议差异见 [[04-产品文档规范/Codex文档技能与校验|Codex文档技能与校验]]；本地整理不代表已发布。

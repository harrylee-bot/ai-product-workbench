本目录回答“产品文档怎么写”。AI 写 PRD 时，必须从产品架构和业务域知识出发，而不是把用户口述扩写成长文。

## 写作原则

- 先说明业务目标，再说明产品对象。
- 先说明主流程，再说明字段和状态。
- 前台、后台、审核、报表、权限、风险不能拆散。
- 历史业务必须写“继承什么、变化什么、影响什么、如何兼容”。
- 新产品必须写“接入哪个能力层、复用哪些能力、新增哪些对象”。

## PRD 必备结构

```text
背景与目标
范围与边界
角色与权限
业务对象
主流程
配置字段
状态与异常
数据与报表
风险与回滚
验收标准
```

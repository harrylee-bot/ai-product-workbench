# PRD标准结构

## 标准章节

| 章节 | 内容要求 |
| --- | --- |
| 背景与目标 | 业务痛点、目标角色、现状问题、期望收益。 |
| 范围与边界 | 本期做什么、不做什么、影响哪些端和模块。 |
| 角色与权限 | 角色、组织、省份、数据范围、操作权限。 |
| 业务对象 | 活动、素材、奖品、渠道、报表、审核、AI 任务等对象定义。 |
| 主流程 | 用户端、后台端、审核端、数据端完整路径。 |
| 配置字段 | 字段名称、默认值、校验、生效范围、历史兼容。 |
| 状态与异常 | 正常、空态、失败、无权限、驳回、发布失败、回滚。 |
| 数据与报表 | 指标口径、筛选项、导出字段、脱敏、审计、延迟。 |
| 风险与回滚 | 资损风险边界、产品控制点、验收口径、安全、权限、外链、个人信息、灰度和回滚。 |
| 验收标准 | 按角色、状态、页面、接口、数据、异常和回归拆分。 |

## 写作要求

- 先写产品逻辑，再写页面和字段。
- 每个字段必须归属到对象。
- 每个状态必须说明触发条件和可执行动作。
- 每个报表指标必须说明口径。
- 每个高风险动作必须说明审核、日志和回滚。
- PRD 不输出“资损表”“资损风险评估表”“资损点检表”等开发填报表格。
- 涉及资损时，PRD 只描述风险场景、产品约束、控制点和验收要求；资损表由开发在技术方案或开发联调阶段补填。

## 历史业务增量章节

历史业务新增必须单独写：

```text
继承范围
新增内容
存量影响
历史兼容
回归验收
```

## 新产品创新章节

新产品必须单独写：

```text
产品定位
能力层落位
新增核心对象
复用现有能力
新闭环流程
数据复盘方式
```

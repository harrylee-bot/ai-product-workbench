# 按业务域写作规则

| 业务域 | 必须覆盖 |
| --- | --- |
| 活动发布 | 模板、页面配置、规则、预览、审核、发布、下架 |
| 素材库 | 上传、专题、标签、审核、水印、下载、引用影响 |
| 抽奖/奖品 | 概率、库存、资格、次数、发放、失败和补偿 |
| 企微/渠道 | 活动码、二维码、短链、发展人、运营位和归因 |
| 商机预约 | 表单、敏感信息协议、门店、套餐、销售品、回传 |
| 签到/打卡 | 业务日期、门店、次数、积分、奖励和重复请求 |
| 报表 | 指标口径、筛选、权限、脱敏、导出和更新时间 |
| AI 能力 | 输入来源、生成结果、人工确认、审核和禁止项 |

每个业务域都要说明正常流程、空态、无资格、重复提交、外部失败、权限不足和撤销/回滚。

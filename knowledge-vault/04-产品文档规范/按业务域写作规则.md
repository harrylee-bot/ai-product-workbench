# 按业务域写作规则

| 业务域 | PRD 必写 |
| --- | --- |
| 活动发布与模板配置 | 活动生命周期、模板适配、配置字段、预览审核、发布下线、测试活动口径。 |
| 素材库与营销资产 | 素材生命周期、标签专题、审核规则、引用影响、搜索筛选、历史兼容。 |
| 奖品券与资损核销 | 库存、概率、资格、领取次数、发放、核销、补偿、对账、资损风险边界与验收口径；不输出开发后置资损表。 |
| 号卡OAO与商机预约 | 门店、套餐、商机、订单、发展人、渠道参数、接口失败和合规。 |
| 数据报表与渠道归因 | 指标口径、筛选条件、权限、导出、脱敏、日志、数据延迟。 |
| AI营销助手与案例库 | 输入输出 schema、来源案例、生成步骤、失败兜底、人工确认、审核。 |
| 权限审核与运营治理 | 角色矩阵、数据范围、审核状态、变更前后值、日志、越权处理。 |

## 组合写作规则

- 活动 + 奖品：必须写资损风险场景、库存、核销和对账；资损表由开发后期补填，不进入 PRD 正文。
- 活动 + 素材：必须写引用影响、素材下线和活动状态影响。
- 活动 + 报表：必须写活动编码、渠道编码、运营位和统计口径。
- AI + 素材：必须写来源案例、素材来源、生成边界和人工确认。
- OAO + 报表：必须写商机、订单、门店、发展人和渠道归因。
- 权限/审核是横切能力，导出、发布、素材、奖品、外链默认要写。

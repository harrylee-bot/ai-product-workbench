# 00-总体执行规格

本条目沉淀用户提供的 **AI PRODUCT WORKBENCH FULL CODEX EXECUTION SPEC**。它定义了系统从 AI Product Compiler OS 演进到 AI Product Company OS 的总路线。

## 项目定义

AI Product Workbench 是 AI Product Compiler OS，并逐步演进为 AI Product Company OS。

核心流程：

```text
User Input
  → Orchestrator
  → Agents
  → ProductDesignState
  → PRD
  → Prototype
  → Patch
  → QA
  → Evolution
  → Self-Generation
```

## 全局规则

- 所有 AI 必须通过 Orchestrator。
- ProductDesignState 是单一事实源。
- 不允许直接修改 PRD 或 Prototype。
- Patch 必须经过 Patch Preview，也就是 Module 0D。
- 所有输出必须是结构化 JSON。
- 所有变化必须版本化。

## Orchestrator 流程

```text
User Message
  → Intent Agent
  → Knowledge Agent
  → Product Agent
  → PRD Generator
  → Prototype Generator
  → QA
  → State Update
```

## Agent 列表

- Intent Agent
- Knowledge Agent
- Product Agent
- PRD Agent
- Prototype Agent
- Patch Agent
- QA Agent

强制规则：所有 Agent 不允许直接写数据库。

## ProductDesignState

```json
{
  "id": "string",
  "projectId": "string",
  "version": 1,
  "title": "string",
  "businessGoal": "string",
  "pages": [],
  "rules": [],
  "configs": [],
  "stateRules": [],
  "exceptions": [],
  "assumptions": [],
  "knowledgeRefs": [],
  "pendingQuestions": []

```

## PRD Compiler

输入：ProductDesignState。

输出：PRD Sections。

章节：

- Background
- Goals
- Users
- Scenarios
- Rules
- Acceptance Criteria

## Prototype Compiler

输入：ProductDesignState。

输出：

- PrototypeSpec
- HTML

## Patch System

```text
User Action
  → PatchDraft
  → Patch Preview
  → Confirm
  → Apply
```

PatchOperation：

```json
{
  "op": "add | update | delete",
  "path": "string",
  "value": {}
}
```

## Patch Preview 0D

必须包含：

- diff viewer
- before/after
- risk panel
- confirm apply

## 后续能力

- Decision Engine V2.1：生成 conservative、restructure、UX improve、full rebuild。
- Review Board V2.2：Product、UX、Tech、Risk、Growth 多角色评审。
- Evolution Engine V2.3：记录 decision traces、success rate、strategy optimization。
- Self-Generation Engine V2.4：系统可以 add agent、modify pipeline、adjust system graph，但必须 preview before apply。
- V3 AI Company System：CEO、Product、Engineering、Design、QA、Growth、Evolution。

# 08-前端改版与预览交互需求

本条目沉淀用户在截图和说明中提出的前端改造细节。它是 [[06-规格文档/07-UI UX UE OS设计系统|UI UX UE OS 设计系统]] 的落地补充。

## 老项目理解

旧工作台表现为：

- 顶部存在系统标题和用户信息栏。
- 左侧以 Projects 为主，更像项目管理工具。
- 中间是 Chat，但执行路径不够自然。
- 右侧直接暴露 Constraint View、Decision View、Evolution View、Company Dashboard 等系统面板。
- PRD 和 Prototype 的预览入口不够明确，用户会问“生成的原型和 PRD 在哪里预览”。

## 新改版目标

系统应该让用户感觉自己在使用 AI Product OS，而不是在操作工具集合。

目标结构：

```text
左侧：最近对话 / 项目入口 / 可展开收起
中间：聊天流 / 唯一输入 / 执行路径流式展示
右侧：AI 结果中心 / PRD 预览 / Prototype 真实预览
```

## 执行路径展示

用户明确提出：

- 执行路径按照执行顺序展示在聊天对话框中。
- 流式展示对用户感知更好。
- 多 Agent 分析处理时应该流式展示 Agent 执行情况。
- 执行路径类似“已运行命令”的可折叠卡片。
- 默认收起，允许展开。

对应模式：[[04-原型模式/执行路径流式展示模式]]。

## 顶部用户栏处理

用户提出参考图三不需要顶部这一栏。

要求：

- 顶部用户信息不再作为主要区域。
- 用户信息可以放到左下角，类似 ChatGPT 侧边栏。
- 顶部应减少系统感和后台感。

## 左侧导航改造

用户提出：

- 图五“项目”改成“最近对话”。
- 左侧历史对话栏可以展开收起，类似图六。
- 收起状态保留图标导航。
- 用户信息在左下角。

交互要求：

- 展开时显示最近对话、项目、应用等入口。
- 收起时保留核心图标。
- 不用复杂工具栏。

## 右侧预览方式

用户提出图七才是应该的预览方式。

要求：

- 左侧可以展示生成说明、代码或对话。
- 右侧展示真实 HTML 页面预览。
- 顶部可以有“代码 / 预览 / html”这类预览上下文，但不能变成复杂工具系统。
- 原型不应只显示 `<html>` 字符串。
- PRD 和 Prototype 应统一在 [[04-原型模式/AI结果中心预览模式|AI 结果中心预览模式]] 中展示。

## 文案语言

用户明确要求：

> 我需要的是一个纯中文的系统。

落地要求：

- 页面标题、按钮、提示、空状态、执行路径、结果中心全部中文。
- 不保留 `Projects`、`Chat`、`Preview` 等英文主标签。
- `AI Product Workbench` 可作为品牌名保留，但系统说明和操作文案必须中文优先。

## 组件改造方向

建议拆分：

- AIInputBox
- AIResultCenter
- ExecutionPathCard
- RecentConversationList
- CollapsibleSidebar
- PrototypePreviewFrame
- PRDPreviewPanel

组件约束：

- 只保留一个输入框。
- 不暴露改写、精简、重构、Diff。
- 执行过程展示为状态卡片，不作为工具按钮。
- 右侧结果中心展示结果，不承担流程控制。

## 验收标准

- 左侧可展开收起。
- 左侧标题从项目强工具感转为最近对话。
- 用户信息位于左下角。
- 中间只有一个 AI 输入。
- 多 Agent 执行路径在聊天流中流式展示。
- 执行路径默认收起。
- 右侧能预览 PRD 和真实 HTML 原型。
- 全系统中文。

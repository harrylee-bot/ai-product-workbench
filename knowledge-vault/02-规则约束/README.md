# 规则约束

规则约束用于限制 AI 行为。任何决策、Agent 输出、Patch、QA 都必须先经过约束上下文过滤。

## 规则类型

- `must_follow`：必须遵守，违反即不可执行。
- `prefer`：优先偏好，用于策略排序。
- `avoid`：避免事项，用于降低不可靠或高风险输出。
- `warn`：风险警告，用于提醒追问、评审或人工确认。

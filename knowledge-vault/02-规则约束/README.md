# 规则约束

规则约束用于记录需求分析、需求文档编写、活动配置、资损评估、报表导出和 AI 工作流落地时必须遵守的业务规则。

## 规则类型

- `must_follow`：必须遵守，违反后需求方案不可直接进入开发或发布。
- `prefer`：优先偏好，用于选择更稳妥、更可复用的方案。
- `avoid`：避免事项，用于降低不可靠或高风险方案。
- `warn`：风险警告，用于提醒补充信息、人工评审或验收加项。

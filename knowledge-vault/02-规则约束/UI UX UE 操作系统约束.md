# UI UX UE 操作系统约束

本约束来自前端改版要求。AI Product Workbench 的前端不是工具箱，而是“用户表达意图，AI 自动决策”的操作系统界面。

## UI 约束

| ID | rule | scope | condition | effect | weight |
| --- | --- | --- | --- | --- | ---: |
| UI-001 | must_follow | agent | 设计工作台主界面时 | 只能保留一个 AI 输入入口。 | 1.0 |
| UI-002 | avoid | agent | 设计操作区时 | 不允许暴露改写、精简、重构、Diff、PRD、Prototype 等工具按钮。 | 0.98 |
| UI-003 | must_follow | decision | 输出结果时 | PRD、Prototype、执行路径统一进入 [[04-原型模式/AI结果中心预览模式|AI 结果中心]]。 | 0.94 |
| UI-004 | prefer | agent | 展示多 Agent 执行状态时 | 默认收起，允许展开查看详情。 | 0.9 |
| UI-005 | must_follow | qa | 页面语言和系统文案 | 必须使用中文。 | 0.96 |

## UX 约束

- 用户只表达目标，不选择执行方式。
- 系统负责拆解任务、匹配知识、生成策略、选择路径。
- 用户可以确认结果，但不需要理解内部技术流程。
- PRD 和 Prototype 自动生成，不作为独立功能入口。
- 复杂流程在聊天流中渐进展示，而不是堆在右侧工具面板里。

## UE 约束

- 执行路径要可感知：见 [[04-原型模式/执行路径流式展示模式|执行路径流式展示模式]]。
- 结果要可预览：见 [[04-原型模式/AI结果中心预览模式|AI 结果中心预览模式]]。
- 左侧历史对话可展开收起。
- 用户信息放在左下角。
- 顶部不需要复杂用户栏。
- 最近对话替代原项目列表的强工具感。
